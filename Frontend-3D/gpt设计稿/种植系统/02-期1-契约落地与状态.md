## 步骤

1. **Core types + Data + audit**。`cropDefinitions` 只有番茄，数字照 §2.2 的占位。`auditCrops` 写好并加 Core 测试；`main.tsx` 挂上（`hasVisual` 传 `resolveVisual !== undefined`）。

3. **`logic/farming.ts`** 按 §4 逐个函数写；每个写入函数返回新对象。几何用 Core 的 `buildingLocalToWorld`（本期从 `residents/spots.ts` 搬到 `Core/logic/buildings.ts`，前端那处改成 re-export）。
4. **物品**：`tomato_seed.seed = { cropId: "tomato" }`；广口壶 `category: Tool`、`power: 1`、`capacity: 12`，注释重写（单位是格）。`ItemStackState.charges`。锄头、普通壶、图纸**本期就登记**（期 2 只补造型和文案）——`auditItemVisuals` 会对没造型的报 warn，本期允许。
5. **`State/farmBeds.ts`**：
   ```ts
   export function readFarmBed(instanceId): { placement; footprint; bed } | null   // 非 farm_plot / 不在场返回 null；state.farm 坏了就给全新实土田（§3 规则）

   export function farmBedsHere(): Array<{ instanceId; placement; footprint; bed }>  // listBuildingsHere() 里的 farm_plot，工地不算
   ```
   footprint 从 `findBuildingLevel(buildingId, levelId).footprint` 取。
6. **`Systems/farming.ts`**：`interactWithFarmCell(target, held?: HeldForFarm)`——`held` 不传就从 `getSelectedStack()` 推（锄头 / 种子 / 壶三种能力块 → `HeldForFarm`）。成功后：`writeFarmBed`、扣种子 `consumeSelectedOne()`、浇水扣 `charges`、收获 `addItem` 两样 + `bumpStat` + `emit("story_signal")`。**先 `canAddItem` 再动田。**
7. **`Systems/farmingRuntime.ts`**：`startFarming()` 返回拆除函数。5 秒 `setInterval`：对 `farmBedsHere()` 每格算 `${stageIndex}|${wet}|${ripe}` 签名，和上一次不同就 `emit("farm_cell_changed", { instanceId })`；`giantCandidates` 非空且 `!isRemoteWorldActive()` → `rollGiant` + `settleGiant` + `writeFarmBed`。听 `weather_changed`：kind 是 Rain / Storm → 每块田里"有苗没熟且干"的格 `waterCell`，一块田一次写入；`save_applied` 后立刻按当前天气跑一次同样的逻辑（读档时正在下雨）。`world_changed{buildings|restored}` / `map_changed` 清签名缓存。
8. **`inventory.ts`**：`canAddItem(itemId, quantity): boolean` 照 `addItem` 的"先合堆再填空格"算能不能全放下，**不写**；`addItem` 的循环抽成两者共用的一个内部函数，别复制一遍。`charges` 进 `SlotStack`、`snapshotInventory` / `restoreInventory` 带上（`state.charges`）。

## 自查

- **状态形状是不是只有一处写**：`writeFarmBed` 是唯一调 `setBuildingState(id, { farm })` 的地方。别处直接 `setBuildingState` 写 farm 就是违规。
- **随机数是不是都从外面递**：`harvestYield(…, roll)`、`rollGiant(seedString, chance)`——logic 里 `Math.random` 出现即违规。
- **时钟**：前端只用 `nowUtc()`（世界钟），`new Date()` 出现在 farming 相关文件里即违规（2026-08-25 那次 `/advance` 拨不动庄稼的教训）。
- **雨水不叠加**：已湿的格不动；连着两天雨也只是各自那天浇一次。
- **删干净**：`Core/src/logic/index.ts` 不再导出 `farm.js`；`farmTuning` 不再存在。
