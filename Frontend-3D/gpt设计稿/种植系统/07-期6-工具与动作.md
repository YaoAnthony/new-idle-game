# 07 · 期 6 · 工具与动作

**目标**：工具不再是"捧在胸前的一件东西"。锄头和水壶**拿在右手上**；站到田上按 F，人先挥锄 / 先倾壶，动作落到那一拍土才翻、水才落；有土块飞、有水滴落；井边装水是把壶往下一探。每件工具是一个**类**（`HeldTool` 的子类），自己写"怎么拿、怎么用、用的时候飞什么"——加一件新工具 = 加一个子类 + 注册表一行，场景代码不认识任何具体工具。房里其他人看得见你挥锄。用户 2026-09-18 原话："工具比较不一样，你按 F 要有动画，并且工具要拿在手上的，建议不是简单的手持物，要有 class 继承，然后每个工具写使用方法和动画效果。"

## 形状（本期新增，01 契约 §14 引用这里）

### 拿法

- `ItemDefinition.carry` 加一档 `"hand"`：单手拿（锄头、两把水壶）。不填仍是捧在身前，`"overhead"` 仍是伞。
- `CharacterRig.handAnchor`：右手掌心的挂点，挂在 `parts.armRight` 上（手球那一点）——胳膊怎么摆，工具跟着走。
- `CarryMode = "none" | "front" | "hand"`：`animateCharacter` 的 `carrying` 布尔改成它。`hand`：右臂微微前抬不摆，左臂照常摆；`front`：原来那套双手端在身前。`carryModeOf(itemId)` 只看 `carry` 字段，不点名物品。
- `mountHeldVisual(rig, itemId, container?)`：手持物挂到骨架上的**唯一入口**（本地 HeldItemView、联机 RemotePlayersView、自动生活的 `setAutoProp` 三处共用）。按 `carry` 选挂点：`hand` → `handAnchor` + 工具类给的 `grip`；其余 → `heldAnchor`（原逻辑）。

### 工具类（`Game3D/Tools/`）

```ts
type ToolIntent =
  | { kind: "farm"; action: FarmAction["kind"] }        // 田上按 F，Systems 已算出会发生什么
  | { kind: "station"; capability: StationCapability };  // 对着家具按 F（井 = water_source）

type ToolGrip = { position: [x, y, z]; rotation: [x, y, z]; scale: number };  // 相对 handAnchor

/** 一次使用的完整说明：多长、哪一拍落下、每一拍人和工具怎么摆、飞什么 */
type ToolUseSpec = {
  name: string;               // 联机手势里带的名字：swing / pour / fill
  duration: number;           // 秒
  impactAt: number;           // 秒；这一拍触发 onImpact（状态真正改变）
  frame(t: number): ToolUseFrame;  // t ∈ [0, duration]，绝对值不是增量
  onImpact?(ctx: ToolEffectContext): void;     // 落下那一拍：土块、溅水、音效
  onTick?(ctx: ToolEffectContext, t: number, dt: number): void;  // 每帧：水流
};
type ToolUseFrame = { armPitch: number; armRoll?: number; toolPitch?: number; toolRoll?: number; bodyPitch?: number };
type ToolEffectContext = { target: Vec3 | null; handWorld(local: Vec3): Vec3; particles: ParticleField; sound(profileId): void };

abstract class HeldTool {
  constructor(readonly definition: ItemDefinition) {}
  abstract readonly grip: ToolGrip;
  /** 这件工具对这个意图有没有动作；有就给动作名 */
  abstract useFor(intent: ToolIntent): string | null;
  /** 动作名 → 说明。子类在 `uses` 表里各写各的 */
  use(name: string): ToolUseSpec | null;
}
class HoeTool extends HeldTool        // uses: swing（till / flatten）
class WateringCanTool extends HeldTool // uses: pour（water）、fill（station water_source）
```

- 注册表 `Tools/index.ts`：`Partial<Record<ToolType, (def) => HeldTool>>`，`hoe → HoeTool`、`watering_can → WateringCanTool`；`toolForItem(itemId)` 查物品定义的 `tool.toolType`。没登记的工具种类（axe / fishing_rod / camera）→ null → 按普通手持物走，和今天一样。
- `ToolPlayer`：绑一具骨架 + 粒子场。`play(spec, { target, onImpact })`、`update(dt)`、`busy`、`cancel()`。每帧在 `animateCharacter` / `applyPose` **之后**写右臂和工具节点的角度（它赢）。`impactAt` 只触发一次；`duration` 到了收场。动作进行中再按 F 忽略。
- **状态在落下那一拍改**：场景先问 Systems 会发生什么（`farmActionAt`），再问手上的工具类有没有对应动作；有 → 播动作、`onImpact` 里才调 `interactWithFarmCell`；没有（种子、空手收获、动作名对不上）→ 立刻调，和今天一样。气泡说"能按"、按了动作落下去一定生效——两边同一把尺子（`farmActionFor`）。

### 效果（`Game3D/Effects/ParticleField.ts`）

一个 `InstancedMesh` 池（小方块），每颗有位置 / 速度 / 寿命 / 重力，`burst({ at, count, color, speed, spread, gravity, life, size })` 一次撒一把，`update(dt)` 推进，落到 `floorY` 以下就死。土块（棕，`PALETTE.farmDirtTilled`）和水滴（`PALETTE.waterBlue`）各一个池，颜色在池上不在粒子上——一池一种材质，两个 draw call 画完全场的效果。不是通用粒子系统，够这两种就行。

### 联机

- `GestureKind.ToolUse = "tool_use"`；`ParticipantGesture` 加可选 `tool: { itemId, use, at?: { x, z } }`。本地播一次动作就发一条；远端 `RemotePlayersView` 收到 → `toolForItem(itemId)?.use(use)` → 那具骨架自己的 `ToolPlayer` 播（无 `onImpact`：状态走 op，见期 5）。
- 协议 **v15 → v16**（手势形状变了）。服务端 `parseGesture` 认 `tool_use`：`itemId` 非空 ≤ 64、`use` 非空 ≤ 32、`at` 两个有限数（可选）。

### 声音

每个动作的 `onImpact` / `onTick` 可以 `ctx.sound("sfx_hoe_hit")` / `("sfx_water_pour")`。**素材和注册表条目归用户**（2026-08-29 分工）：`playOneShot` 对没登记的 id 是空操作，接线先留着。

## 自查

- **场景不认识具体工具**：RoomScene 只调 `toolForHeld()?.useFor(intent)`；哪件工具管哪个动作在子类里。
- **状态和动作一把尺子**：动作只在 `farmActionAt` 给出非 none 时才播；`onImpact` 调的还是 `interactWithFarmCell`，气泡和结果不可能对不上。
- **replay 不发手势**：远端收到手势只播动作；op 到了状态才变。两条各管各的，重复到达也只是多挥一下。
- **自动生活复用同一套**：`autoWater` 不另写动画，播的就是 `WateringCanTool` 的 pour / fill。
- **数字在类里**：抬多高、落多快、几颗土块、水滴多密都在各自的工具类顶部，不散在场景里。

## 收工记录（2026-09-18）

- Core：`carry` 加 `"hand"`（锄头、两把壶）；`GestureKind.ToolUse` + `ParticipantGesture.tool?`；协议 v15 → **v16**。Backend `parseGesture` 认 `tool_use`（itemId ≤ 64、use ≤ 32、at 两个有限数）。
- 骨架：`CharacterRig.handAnchor`（右手掌心，挂在 `armRight` 上）；`animateCharacter` 的 `carrying` 布尔改成 `CarryMode`——`hand` 时右臂微抬不摆、左臂照常。
- 挂法：`carryModeOf` / `mountHeldVisual` 是唯一入口（本地、远端、自动生活的壶三处共用），单手拿的按工具类的 `grip` 摆好并把握法记在 `userData.grip`。
- 工具类族 `Game3D/Tools/`：`HeldTool`（`grip` / `useFor(intent)` / `uses` 表 / `use(name)`）、`HoeTool`（swing：抡起 0.22 s → 落下 0.12 s → 收回 0.26 s，落下那一拍 9 颗土块）、
  `WateringCanTool`（pour 1.25 s：壶绕手心前倒、每秒 60 滴从壶嘴落向格心、0.3 s 那一拍状态才改；fill 0.8 s：探下去 0.45 s 那一拍装满、几滴水跳出来）、
  注册表按 `tool.toolType`（没登记的斧头 / 鱼竿 / 相机照旧当普通手持物）、`ToolPlayer`（每帧写右臂 + 工具节点，impact 只触发一次，进行中拒第二次，`cancel` 不触发 impact）。
- 效果 `Game3D/Effects/ParticleField`：一色一个 `InstancedMesh` 池，土和水各一个，场景建、本地和远端播放器共用。
