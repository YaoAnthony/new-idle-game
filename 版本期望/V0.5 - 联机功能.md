# 联机功能

在 V0.5 版本中，主要实现房主创建世界房间，以及房客加入房主世界。

联机过程中，房主的 `WorldSave` 作为当前世界。房客只能通过服务器允许的指令修改这个世界，房客自己的 `ownWorld` 不会被替换或修改。

联机应当可以执行以下功能：
- 对话功能：互相交流会有聊天气泡，且左下角出现人物的聊天记录
- 交易: 互相可以丢弃物品，捡起物品
- 做任务: 任务可以正常进行，每日任务会共享主机进度（如果两人做一次每日，则算完成2次）
- 世界同步: 世界应当完全同步

联机应该会禁止以下功能：
- 任务进度

## 创建房间

1. 房主点击开启联机。

2. 房主 Client 连接 WebSocket Server。

3. 房主发送创建房间请求：

```ts
type CreateWorldSessionRequest = {
  schemaVersion: number;

  host: PublicPlayerProfile;
  world: WorldSave;
};

type PublicPlayerProfile = {
  playerId: string;
  name: string;
  avatar: string;
};

```

4. Server 验证并暂存房主世界，创建联机会话：

```ts

type CreateWorldSessionResult = {
  sessionId: string;
  joinCode: string;
  revision: number;
};

```

5. Client 向房主显示唯一的邀请地址

## 加入房间
1. 房客在出门区域填写邀请地址

比如 133 yonge str

2. 房客 Client 连接 WebSocket Server，并发送：

```ts
    type JoinWorldRequest = {
        joinAddress: string;
        player: PublicPlayerProfile;
    };
```

3. server检查address 是否也开启了联机功能，有存档，如果有的话，继续执行，否则返回错误

## 联机同步
玩家移动只同步运行时位置，不修改 WorldSave。

家具摆放、制作、天气变化等耐久操作发送给 Server。Server 验证成功后更新房间中的 WorldSave，增加 revision，再向所有参与者广播最新世界状态。

房客不能直接上传修改后的完整 WorldSave 覆盖房主世界。

## 退出房间
房客退出时，清除远程世界并回到自己的 ownWorld。

房主结束联机时，Server 返回最终的 WorldSave 和 revision。房主 Client 将最终世界写入：

gameSave.ownWorld = finalWorld;


## 意外断线
房主意外断线后，server会保留一段时间等待重连，时间大概为1min

房主重新打开页面的时候，会检查是否有联机状态，如果有，将本地的存档更新到云端最新的存档
