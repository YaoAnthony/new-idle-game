# prompt/

记录用于生成游戏美术素材的图片生成 prompt，方便复用、对比迭代效果。

## 使用方式

生成图片素材时，创建一个文件 `<主题>.md`，格式：

```md
# <素材名称>

## 用途
用在哪里（比如"标题背景"、"XX家具图标"、"XX事件插图"）

## v1 (日期)
生成方式：Codex imagegen / 其他
Prompt:
> ...

结果：output/xxx.png
评价：...

## v2 (日期)
Prompt:
> ...

结果：output/xxx.png
评价：比 v1 好在哪 / 还有什么问题
```

同名素材的多次尝试都写进同一个文件里，保留完整迭代历史，而不是新开文件。
