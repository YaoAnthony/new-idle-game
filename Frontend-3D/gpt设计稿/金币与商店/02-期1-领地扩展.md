## 用户要测什么

> 一开始位置很小，随着时间扩展，领地越来越大。**必须保证能建筑的网格同步放大。**

做完按这个玩一遍（用户视角验收）：

1. 新档开局，只拥有 **C3** 一格（15×15），**房子是收起的**（一块空地）；领地内没有田、树、墙、广场，四周杂草丛生、一圈木桩绳索
2. 走到绳索边被拦住；`/goto town` 报"领地未扩展"（东桥在 D2，隔两格）
3. 在自己地里摆长椅——能摆；虚影挪到绳索外——变红，提示"这块地还没开"
4. 锁定格里能**看见**一两处特别建筑（废井、石碑），走不到，但看得见
5. `/territory unlock C2` → 绳索退到新边界、原来放不下的位置能放了
6. 再 `/territory unlock D2` → 能走到东门、上东桥、`/goto town` 成功
7. 存档读档，已开的格还在

## 格盘（base 图）

| | A（x −40..−25） | B（x −25..−10） | C（x −10..5） | D（x 5..20） |
|---|---|---|---|---|
| **1**（z −27..−12） | A1 | B1 | C1 | D1 |
| **2**（z −12..3） | A2 | B2 | C2 | **D2 · 东桥头** |
| **3**（z 3..18） | A3 | **B3 · 南桥头** | **C3 · 开局** | D3 |

> 实算脚本：`for c in range(4): x0=-40+15*c` / `for r in range(3): z0=-27+15*r`，点落在哪格一查就出。

**邻接 = 共边**。开局 C3 → 可开 C2 / B3 / D3。
**到东桥两步**：C3 → C2 → D2（或 C3 → D3 → D2）。到南桥一步：C3 → B3。
> 想让南桥也要两步：把开局格挪到 D3。**本期按 C3**（东桥两步、南桥一步），旋钮记在这。

——那里是地理不是领地，能不能走由既有规则（陡度、桥面）决定。"D2 没开就到不了东桥"自然成立：
桥头在 D2 的边上，D2 锁着就走不到那条边。

```ts
// Core/src/types/map.ts — MapDefinition 追加
/** 这张图的地块。没有 = 整图能走能建（小镇、店铺） */

正式驱动接上时零新机制。`initial` 的格不写进去，永远算拥有。

// Maps/base/layout.ts 追加
/**
 * 院子 = 一个没有墙的房间，网格盖住**整块领地**（60×45），锚点在领地中心 (−10, −4.5)。
 * roomId 必须等于 baseMapDefinition.outdoorRoomId（"yard"）：groundMap 靠这条判断

 *
 * **网格从第一天就是最大**：领地扩展只改"哪些格可用"，不改网格尺寸。

 * 已放置家具会集体错位——这是必须避开的坑。

export function generateYard(): RoomSave {
  return {
    roomId: "yard",
    floorGrid: { width: 60, height: 45 },
    walls: {},
    floor: 0,
    anchor: { x: -10, z: -4.5, elevation: 0, facing: Facing.North },

}
```

### 1B-4 看得见的边界 + 锁定格的样子（T7）

**围栏**：`Frontend-3D/src/Game3D/World/TerritoryView.ts`（新）。沿 `ownedBoundaryEdges` 立木桩（每 2 格一根，
`cylinder`）+ 绳（细 `box`），高 0.9，色 `woodMid` / `paperShade`。挂 scene 层级；听 `world_changed`
reason `territory` → 整组重建（地块变化是稀有事件，不做增量）。
**不注册 obstacle**：拦人的是 `isInsideTerritory`，围栏是它的可视化，两者不能各拦各的。

**锁定格的样子**（同一个文件，同一次重建）：

- **杂草**：锁定格内按格心撒草丛（`blob`，`leafGreen` / `caneGreen` 抖色，密度约每 3×3 格一丛；1B-0 清场之后格里没有别的东西，杂草不用避让，
  用 `hash01(格坐标)` 定位置和大小——确定性，每次重建长一样）。开了的格不撒
- **特别建筑**：每格 `lockedVisual` 给一个地标（`landmarkId` + 位置），**只在该格锁定时出现**，解锁后消失。
  这就是 T7 的"勾引玩家"。本期给三个够了（其余格只有杂草）：

  | 格 | 地标 | 为什么勾人 |
  |---|---|---|
  | D2 | **旧桥头灯柱**（石座 + 铁灯） | 看得见通往小镇的路在那边 |
  | A2 | **废井**（石圈 + 木架） | 西边最远，给一个"那儿有点东西"的理由 |
  | B1 | **半塌的石碑**（斜插的石板） | 北面后庭，暗示这块地有故事 |

  地标是**纯布景**：不注册 obstacle、不进占用图、不可交互。走不到它们（格是锁的），只能看见。
  以后要让它们变成真东西（修好的井、能读的碑），是那时候的事。
