## 2. 作物注册表（Core）

### 2.1 类型 `Core/src/types/farming.ts`

```ts
import type { ItemId } from "./items.js";
import type { LocalizationKey, VisualId } from "./base.js";
import type { UtcTimestamp } from "./time.js";

export type CropId = string;

/** 一段造型：进度到 at（0~1）起用这个 visual。首项 at 必须是 0 */
export type CropStage = { at: number; visual: VisualId };

/** 作物需要什么。今天只有水；撒肥料 = 这里加一种 kind + 格上多记一个时间戳 */
export type CropNeed = { kind: "water"; lastsMinutes: number };

export type CropGiant = {
  /** 边长。今天只支持 2 */
  size: 2;
  /** 四格同时成熟那一刻掷一次的概率 */
  chance: number;
  /** 产量相对"四格分开收"的倍数 */
  yieldMultiplier: number;
  visual: VisualId;
};

export type CropDefinition = {
  cropId: CropId;
  /** `crop.<id>`：气泡、图鉴、成就描述用 */
  localizationKey: LocalizationKey;
  seedItemId: ItemId;
  /** 累计**湿润**多少分钟成熟 */
  growMinutes: number;
  /** 升序；进度 ≥ at 的最后一段就是当前造型 */
  stages: readonly CropStage[];
  needs: readonly CropNeed[];
  harvest: {
    itemId: ItemId;
    /** 闭区间，随机 */
    count: readonly [number, number];
    seeds: readonly [number, number];
  };
  giant?: CropGiant;
};
```

## 3. 田和格的状态（进存档，住 `BuildingPlacement.state.farm`）

```ts
export type FarmSoil = "packed" | "tilled";   // 湿不湿是算出来的，不进这个枚举

export type FarmPlant = {
  cropId: CropId;
  sownUtc: UtcTimestamp;
  /** 已经结算进去的湿润生长毫秒 */
  grownMs: number;
  /** grownMs 结算到哪一刻。此刻到 min(now, wetUntil) 之间的湿润时间是"活"的部分 */
  settledUtc: UtcTimestamp;
};

export type FarmCell = {
  soil: FarmSoil;
  /** 湿到什么时候。没有 / 过了 = 干 */
  wetUntilUtc?: UtcTimestamp;
  plant?: FarmPlant;
};

export type FarmGiant = {
  cropId: CropId;
  /** 窗口左上格（本地格坐标，col 沿宽、row 沿深） */
  col: number;
  row: number;
  size: 2;
};

export type FarmBed = {
  /** 长度 = footprint.width × footprint.height，下标 = row × width + col */
  cells: FarmCell[];
  /** 最多一颗。被它盖住的四格 plant 保留（记 cropId 用），收获时一起清 */
  giant?: FarmGiant;
  /** 掷过巨大判定的窗口 `"col,row"`，不重掷。收获后清掉对应项 */
  giantRolled?: string[];
};
```

**规则**：
- `state.farm` 缺失、`cells` 长度对不上、任一格形状不对 → `parseFarmBed(state, cellCount)` 返回**全新实土田**。老档里 `seedItemId / plantedUtc / wateredUtc / stage` 四个旧键一律忽略，下一次写入时显式写成 `undefined` 抹掉。**不做存档迁移**，`SAVE_SCHEMA_VERSION` 不动。
- 不存阶段、不存"湿"、不存"缺水"，全部由 §4 现算。
- 联机：住 `buildings` 切片，随整片刷新走；即时同步靠期 5 的 op。

```ts
// ---- 写入（返回新 bed，不改入参）----
export function tillCell(bed, index): FarmBed;
export function flattenCell(bed, index): FarmBed;                        // 只对"耕地·空"合法
export function sowCell(bed, index, cropId, nowUtc): FarmBed;            // plant = { cropId, sownUtc: now, grownMs: 0, settledUtc: now }
/** 结算活的那段进 grownMs，再把 wetUntil 推到 now + lastsMinutes。对"没苗的耕地"也合法（浇空地无害） */
export function waterCell(bed, index, crop, nowUtc): FarmBed;

export function harvestYield(crop, giant: boolean, roll: () => number): { items: number; seeds: number };
//   普通：items ∈ count 区间；巨大：round(4 × 平均(count) × yieldMultiplier)，seeds = 4 × 随机(seeds)

// ---- 巨大果实 ----
/** 还没掷过、四格同种、四格都熟、没有现存 giant 的窗口 */
export function giantCandidates(bed, footprint, crops, nowUtc): Array<{ col: number; row: number; cropId: CropId }>;
/** 种子串 = `${worldId}|${salt}|${instanceId}|${col},${row}|${四格 sownUtc 按下标拼}`，hashSeed → seededRandom 取一个数 < chance */
export function rollGiant(seedString: string, chance: number): boolean;
/** 掷完写回：中了写 giant，没中只记 giantRolled */

// ---- 给自动生活 ----
export function thirstyCellsOf(beds: ReadonlyArray<{ instanceId; placement; footprint; bed }>, crops, nowUtc): Array<{ instanceId; index; x; z }>;
```

**生长的数学**（一处写清，测试钉死）：
- `wetUntil = parse(cell.wetUntilUtc) ?? −∞`；`wet = now < wetUntil`。
- `grownTotal = plant.grownMs + max(0, min(now, wetUntil) − parse(plant.settledUtc))`。
- `progress = min(1, grownTotal / (growMinutes × 60000))`；`ripe = progress ≥ 1`。
- `waterCell`：先 `grownMs = grownTotal, settledUtc = now`，再 `wetUntilUtc = now + lastsMinutes`（不叠加：湿着再浇是 `wet_enough`，进不来）。
- 成熟后一切冻结：不再看水。

`hashSeed / seededRandom` 现住 `Data/dailyTasks`，期 1 搬到 `Core/src/logic/random.ts`（Data 那边转发），logic 不该 import Data 里的算法。

## 5. 交互分派（前端）

### 5.1 目标

`RoomScene.interactTarget` 联合加一种：`{ kind: "farmCell"; instanceId: string; cell: number }`。`refreshInteractTarget` 里**先于建筑那一支**问 `farmTargetAt(probeX, probeZ)`（Systems/farming）：探针点落在某块 `farm_plot` 的占地里 → 取那一格，距离记 0，直接赢。站在田边、探针在田外 → 照旧落到 `building` 那支（开管理面板）。**田上 = 种地，田边 = 管理**，不给同一个 F 两种解释。

### 5.2 气泡

`farmHintFor(target, nowUtc): { localizationKey; params?: Record<string, string>; action?: "interact" }`，按 §4 的 `FarmCellView` × 手上：

| 格 | 键 | 参数 | 有 F 吗 |
|---|---|---|---|
| 实土 | `farm.hint.packed` | | 手持锄头才有 |
| 耕地·空 | `farm.hint.empty` | | 手持种子 / 锄头才有 |
| 有苗·干·没熟 | `farm.hint.thirsty` | `{crop}` | 手持有水的壶才有；壶空 → `farm.hint.can_empty` |
| 有苗·湿·没熟 | `farm.hint.growing` | `{crop} {time}` | 无 |
| 成熟 | `farm.hint.ripe` | `{crop}` | 有 |
| 巨大 | `farm.hint.giant` | `{crop}` | 有 |

`InteractHint` 加 `params?`，气泡组件 `t(key)` 后逐个 `.replace("{k}", v)`（`{time}` 由前端 `formatDuration` 出"1 小时 20 分"）。气泡挂在格中心 y = 0.6。

### 5.3 F

`interact()` 加两支：
- `farmCell` → `interactWithFarmCell(target)`（Systems）。结果 `ok` 时按动作放一句 toast（收获才有：`farm.toast.harvested`）；`none` 时什么都不做——气泡已经说清了为什么。
- `station` 的 `water_source`（新 capability，`stationCapabilityOf` 里排在 `Sitting` 前）→ 手持水壶 → `fillWateringCan()` + toast `farm.toast.filled`；否则不动。

### 8.3 剧本（RoomScene `autoWater`）

```ts
export type WateringStop =
  | { kind: "fill"; instanceId: string }                       // 井的家具实例；站位由场景用"贴占地一圈挑格"算
  | { kind: "pour"; target: FarmTarget; at: { x; z }; covers: FarmTarget[] };   // 站到格中心
```

`planWateringTour(from, can)`（Systems，纯规划，不寻路）：贪心——手上没水先 `fill`；每次挑离当前位置最近的缺水格，`covers` = 以它为心 `power` 半径内的缺水格；扣一格水；直到清单空或 `waterMaxStops`；水用完且还有缺水格 → 再 `fill`，最多 `waterMaxRefills` 次。

场景：`stops` 为空 → 原地视同到位。否则：出门（把 `autoOuting` 里"走到门里一步 → 开门 → 出去"和"回门里 → 关自己开的门"抽成 `autoStepOut(next)` / `autoComeHome(next)`，两处共用）→ `setAutoProp(can.itemId)` 手上挂壶 → 逐站：`tourWalk(站位)` → `tourWait(waterPourSeconds)` → `performWateringStop(stop)` → 下一站；走不到的站跳过 → 回屋 → `setAutoProp(null)` → `arrived()`。`setUmbrellaOpen` 改名 `setAutoProp(itemId | null)`，伞和壶走同一处。
