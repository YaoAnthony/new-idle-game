# 17 · 开场二：桌上的日记本

> 状态：**已完成** · 2026-09-12 · 前置：14 开场（门开为止） · 收工记录见文末
>
> 一句话：日记本不再是右上角天生就有的按钮，而是魔女留在桌上的一本书。按 F 它飞起来、
> 飞进右上角变成按钮，然后弹教程。开场链从「门开」接到「开始记任务」。

## 玩家看到什么

1. 醒来时屋里就有一张桌子（不再从纸箱里拆出来），桌上放着一本绿皮日记本（参考图：`public/icons/journal.png`，绿封面、深绿书脊、奶白圆牌上一片叶子）。右上角**没有**日记本按钮。
2. 走近桌子，气泡「F 日记本」。按 F：
   - **3D 段（约 0.8 s）**：书从桌面缓缓飘起、转正朝向镜头、飞到画面正中央，停一拍。
   - **嗖（约 0.5 s）**：从画面中央一道星光尾迹（沿用 NotePanel 那套四角星粒子）甩向右上角，书在尾迹里缩小；到位那一刻右上角的按钮弹出来（0 → 1.15 → 1），按钮图就是这本书。
   - 教程 Modal 弹出（走通用 Guide 面板，`guideId: "diary"`）。
3. 关掉教程，桌上没书了，右上角有按钮，点开是日记本。之后一切照旧。

## 定下来的（用户 2026-09-12）

- 初始纸箱里不再有桌子；屋里默认有一张桌子，桌上有日记本（要建模）。
- 一开始没有右上角那个 icon；拿到本子之后才有，而且 icon 换成这本书的图。
- 动画：F → 书慢慢飞起到屏幕正中 → 嗖一下（沿用星光粒子）到右上角变成 icon → 弹教程。
- 3D 转 2D 的那一下做完必须自己渲图看。
- 图用 asset-prep 抠白底。`journal.png` 这个名字可以改。

## 我定的（可否）

| 事 | 定法 | 为什么 |
|---|---|---|
| 图名 | 就叫 `journal.png`，物品 id 也叫 `journal` | 图标按 `/icons/<itemId>.png` 取，名字 = id 最省事 |
| 本子是什么 | 一件**台面小物**（`PlacementSurface.Surface`），新能力 `FurnitureCapability.Journal` | 桌面小物系统现成（`logic/surfaces`），F 的目标竞争也是按能力分派的现成路子；不另造"可拾取道具" |
| 桌子位置 | 屋里南窗下、床对面那侧，具体格号实装时按房间量 | 醒来坐起视线放平正好看见它；不挡门到床的路 |
| 飞行分两段 | 3D 段在 RoomScene（真的 Object3D 飞），到画面中央后**投影成屏幕坐标交给 DOM**，第二段是 DOM 里一张 `journal.png` 飞到按钮 | 3D 物件飞不进 HUD 层；在中央交接时书的屏幕大小两边对齐，看不出换了东西 |
| 星光 | 把 NotePanel 里的 `useSparkles` 抽成通用 `sparkTrail`（给一条屏幕轨迹 + 时间，撒星） | 用户点名沿用；抽出来两处共用，别复制一份 |
| 剧情接法 | 飞行结束发信号 `journal_taken` → 规则 `unlock_feature("diary")` + `show_guide("diary")` | 和门上信封一样：场景只发信号，后果全在 storyRules |
| 老档 | 存档迁移 v51：已有存档直接把 `diary` 写进 `unlockedFeatureIds` | 老玩家早就在用日记本，不能让按钮消失、也不能让他们桌上再长出一本 |
| 教程图 | `guides.ts` 加 `diary` 条目，**图先留空**（面板画占位框） | 日记本的六格图还没有；你出图后放 `public/ui/tutorial_diary.webp` 填上即可 |
| 联机 | 房客世界里桌上没书（feature 是房主的）；房客 HUD 按钮跟房主功能走 | 和条子同一条规则 |

## 风险

- **桌子被搬走时本子怎么办**：台面小物跟宿主走（surfaces 那套已处理）。拿本子之前能不能搬桌子，实装时看现有规则，若能搬就让本子跟着桌子走，不做特殊处理。
- **3D→2D 交接的尺寸对齐**：书在中央时的屏幕像素高度要量出来给 DOM 段当起始尺寸，否则会"变了一本书"。这是用户点名要渲图看的地方。
- **headless 截图 3.3 s 一张追不上动画**：3D 段用手动推帧渲染，DOM 段抓画布 / 关键属性，和落款那次一样。
- **教程无图**：面板会显示"示意图待补"占位，上线前要补。

## 明确不做

- 不改日记本面板本身；不改任务 / 奖励规则。
- 不做"本子放回桌上"；不做本子进背包。
- 第一条任务的预填、魔女的旧记录、第一笔奖励寄家具——那是上一轮聊的三拍里另外两拍，这一期只做「拿到本子」这一拍，用户另定。

## 收工记录（2026-09-12）

**做成的样子**：纸箱里没有桌子了；新世界屋里南窗下种一张桌子（格 (5,11) 朝南），
桌上半格 (1,0) 摆着 `journal`（台面小物，能力 `Journal`，不可交易、无价）。开局右上角没有
日记本按钮（缩到 0、不吃指针，位置照旧，飞行终点要量它）。走近桌子气泡「F 日记本」，按 F：
`RoomScene.startJournalFlight` 把视图克隆成飞行体、材质副本加半档自发光、实例当场删掉、
气泡立刻撤；`JournalFlight` 飘起 0.45 s → 飞到镜头正前方 0.7 s（封面朝镜头，占画面高 30%）→
停 0.25 s；投影成屏幕几何发 `journal_flight_handoff`；`Components/Diary/JournalArrival` 在同一位置
放同图的 <img>，0.55 s 嗖到按钮，星光尾迹 + 落地炸一圈（星光抽成 `Components/Effects/sparks`，
信纸落款共用），落地发 `journal_taken`；规则 `opening_journal`：`unlock_feature diary` + 0.65 s 后
`show_guide diary`。按钮 0 → 1.18 → 1 弹出，图就是 `/icons/journal.png`。老档迁移 v52 补 `diary`。

**和计划不一样的地方**

| 计划写的 | 实际 | 为什么 |
|---|---|---|
| 教程图先留空 | 用户当天给了两张（`tutorial_mission_1/2.webp`），引导面板加了多图翻页 | 图到了 |
| 教程紧接落地弹 | `show_guide` 加 `delayMs`，晚 0.65 s；**引导面板改成排队**：有面板开着就等栈空 | 落地同一拍弹教程，按钮弹出被盖住；晚 0.65 s 又撞上玩家立刻点按钮——教程压在日记本上（用户抓到） |
| 星光"沿用" | 从 NotePanel 抽成通用 `SparkField`（坐标 CSS 像素，寿命走墙钟） | 两处共用一份 |
| — | 飞行体材质加自发光 | 封面朝镜头时光在它身后，原样渲染是一块暗绿板子（截图验到） |
| — | 起飞时立刻 `refreshInteractTarget()` | 气泡限流检查在面板开着时停，「F 日记本」会挂到教程关掉 |
