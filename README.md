# new-idle-game

这个游戏的关键词：联机，挂机，宠物养成，聊天，做任务，听音乐，正常白噪音

## 第一天流程

每个人会以租到房子的名义去到在一个房子里，玩家会被随机分配到初期可以选择的3个地区的房子，玩家会随机到某一种屋子里面生活

(比如森林系的屋子，你会发现一个龙猫直接躺在角落呼呼大睡)

刚搬家到这个房子，系统会指引你按B打开背包，把随身的物品拿出来，如果类型是家具，就可以放在地上

如果你把工作台第一次拿出来放在地上，系统会指导你按f键打开工作台，告诉你他可以合成一些家具（未来我们需要升级工作台才能做更好的家具之类的）


家具可以通过鼠标右键点击举起，然后左键放在地上，小人走过去F可以进行交互

背包里一般会随机有1种家具的素材，你需要合成它，比如合成一张桌子椅子

期间会出现一些镜头移动事件，然后就会发现一些可爱的小动物（大胖猫除外，人家一大个杵在那，看不见都难）

你可以和这些宠物进行互动以获取最初的印象

他们一般会有需求，如果你想满足需求，我们就会引导你解锁一个关键的功能：行动（还没想好名字）

点开UI会看到可以选择做4种事情，一开始都是空的，但是基于家里比较简陋，你可能只能选择一种任务，比如家里只有桌子就可以选择学习，家里有垫子就能运动任务，有画笔啥的，就能创作，有床就能能休息

总之有4个类别：运动任务/ 工作or学习任务 / 创作任务 / 休息任务（取决于你应对不同的生物，以及家里有什么）

如果家里没有某个家具，则没办法干上面的某个事情，如果有的话，你需要自己创建一个这个系列的事情，创建好了之后，会回到list表，点击开始

然后游戏里的人就会开始做对应的事情，他会耗费你定下的时间

做完之后，里面的角色就会获得一些物品，一开始肯定有能过剧情的物品（指的是和小宠物互动的物品）

然后就可以给他物品，小宠物就会有对话，你就会了解到一些他的一些信息

结束之后会获得一些对应的物资？一般他们会说下次出门之后会给你带回来点有趣的东西

小宠物会给你属于他的一些素材，这时候玩家会饿了，就可以提示去厨房区做饭

（这里拿番茄炒蛋饭举例）

提示用户可以将背包里的锅拿出来，放到灶台上，然后米放进去就可以开始煮米

背包里还有番茄和鸡蛋，你就可以先加鸡蛋，然后加番茄，进度条结束了之后，就做好了，再背包拿一个盘子就可以接出番茄和炒饭

你就可以自己吃了，恢复体力

这个时候就会有个完整的tutoial图 ： 做任务 -> 获得奖励 -> 消耗（这里会有分支，制作家具，或者消耗给小动物或者自己吃掉） 的流程

你获得材料可以接着做一些家具，比如做出了哑铃之后，就可以接锻炼任务

这个时候一般来说4个分类做的任务，都能获得一些素材，这些素材最终都能解锁最基础的4项任务所对应的家具

因为一来就是下午，且做3~4个任务，已经就到晚上了，就可以睡觉了

第一天只能打地铺

睡醒起来，小动物一般就不见了，但是主线任务会让说听到什么地方有声音，让你去看看


你去看，消失的小动物就会出现，来找你，说上次的xxx很不错，给你带来了点东西，希望以后还能接着和你相处

你就会获得有意思的小家具，可以放在地上

这时候妈妈给你打电话，问你生活怎么样啦，说如果物资不够的话，之后会给你带一个每日任务小机器过来，他也可以生成一些你需要的东西

之后就是循环的在里面做任务




下面则是一些事件会解锁的功能：

# 救助大河

在某一天暴雨天，你会听到门口有敲门的声音，如果你选择交互的话

你开门他会倒在你的面前，你需要尝试救助他

救助个一天之后，她就会苏醒，很感谢你救了他，听说了你的信息，然后提出如果未来你想要出行，可以来找他，他会带你出门，但是会要求`旅行券`

从此获得去别的地方的机会（目前只做联机功能）

# 联机功能

在工作台合成了交通工具和防具就可以出门了，出门可以去朋友家窜门，和朋友一起做任务

联机状态下，一起填充满了每日任务，则会获得友情印章
联机状态下，双方都能看到对方在做什么事情，但是选择任务也会依赖于对方的家具

可以兑换以下物品：
- 双人家具
- 拜访动作
房间白噪音小组件

# 事件系统

# 每日任务

相对于todo性质的任务，我们也有每日任务,每日任务会送一些平时系列任务没办法生成的物品：

邮票 / 地址碎片	用于写信、解锁特殊来信或神秘收件人
天气瓶	临时改变房间天气/白噪音，比如雨瓶、风瓶、晴瓶
胶卷 / 相纸	拍照功能消耗品
燃料罐 做饭需要用的能量
旅行卷 用来和`大河`交易，换取旅行的机会

# 小宠物系统

在未来的日子，会解锁和他们讨论的技能

## 好感度

宠物有针对每个人，其他宠物的记忆，其中包括好感度：

下面是目前的设计
陌生访客 → 熟悉的住客 → 生活伙伴 → 家人

设计上不会显示好感度具体数值，但是会通过以下表现表达好感度

- 开始睡在玩家附近
- 愿意吃玩家做的饭
- 玩家做任务时在旁边陪着
- 主动带东西回来
- 出门前会询问玩家意见
- 朋友来访时不再躲起来

好感度只会在经历一些宠物事件以及陪伴事件而变化

## 喜好

宠物会有自己的喜好，如：爱吃、能吃、不喜欢、不能吃的物品
- 与天气相关的偏好

## 派遣
派遣系统会有一套流程，初期宠物会自己直接出门，随机前往某个区域，并带回那个区域的产物

未来的日子，小宠物会和你交谈，问你更愿意前往哪个地方


## 成长 / 进化

宠物可能会有进化的趋势，目前暂时不考虑，添加成长值即可

厨房里一开始只有灶台，下面是各种表，具体参考overcook，只有特定的食材才能放到特定的厨具，放进去之后，就会开始运转，时间转动放食材，就会自己熟
火候只影响品质，不会烧毁稀有材料
已解锁菜谱，未来可以委托某些小动物炒菜

# 植物系统

当你获得黏土，会制作花盆，花盆可以种植植物

工作台可以制作化肥箱

但是化肥箱很臭，如果你只有一个区域，化肥箱造不了，因为太臭了你住不了

但是化肥箱可以允许你把过期的食物放进去变成肥料，可以养活一些更高级的植物

肥料拥有等级，高等级的肥料，也需要高等级的食物和配方

# 正反馈

- 生存
- 培养宠物
- 家里装修

# 负反馈

- 食物会过期
- 做好的便当

# 疲劳值 和 饥饿值

疲劳值是控制你做任务次数而出现的，每次做除了休息任务以外的事情时，就会消耗疲劳值，越多就越累
饥饿值用于解决你吃的食物，太饿了也没办法做任务
0饥饿度会停止做任何事情

# 声音系统

声音采用对主角环境的判断，目前有以下音效：

天气：

下雨天 -> 雨声
刮风天 -> 风声


家具：

壁炉 -> 加入火焰声
鱼缸 -> 加入水泡声
风铃 -> 刮风天响
植物 -> 雨后有叶片滴水声
老钟 -> 夜晚有轻微滴答声
煮水 -> 咕噜咕噜的滚水声


宠物：

睡觉：轻微呼噜
开心：小铃铛/脚步声
饿了：轻轻叫一声
在旁边玩：纸球、爪子、尾巴扫地
水生宠物：吐泡泡

个人：

学习 -> 纸笔声
运动 -> 轻微踏步声
创作 -> 画笔声
休息 -> 房间更安静
