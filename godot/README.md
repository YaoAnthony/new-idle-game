# Godot Game Client

This directory will contain the primary top-down 2D game client for `new-idle-game`.

The game combines real-life focus actions with a magical home-life loop: complete an action, receive resources, and spend those resources on survival, pets, crafting, and home decoration.

## Documentation entry points

- `AGENTS.md`: mandatory instructions for implementation agents.
- `HARNESS.md`: complete development harness and execution workflow.
- `docs/SPEC.md`: product requirements and scope.
- `docs/REQUIREMENTS_ANALYSIS.md`: traceability from the original README to required systems.
- `docs/CONTEXT.md`: domain language and state ownership.
- `docs/DECISIONS.md`: accepted architecture decisions.
- `docs/ARCHITECTURE.md`: runtime and module architecture.
- `docs/DATA_MODEL.md`: data-driven content and persistence model.
- `docs/CONTENT_PIPELINE.md`: content and asset workflow.
- `docs/TESTING.md`: automated tests, playtest evaluations, and quality gates.
- `docs/OPERATIONS.md`: build, release, security, privacy, and recovery guidance.
- `docs/ROADMAP.md`: dependency-ordered delivery stages.
- `docs/tasks/`: independently executable work items.
- `docs/evals/`: repeatable player-flow evaluations.

The current repository is in harness and architecture preparation. Empty `.gd` and `.tscn` files are placeholders, not implemented gameplay.
