# 工作台系统

在我们的游戏当中，有许多需要合成的物品，下面是应当有的数据机构，也是采用数据表的结构

```ts
type RecipeDefinition = {

    id: string;
    localizationKey: string;
    stationCapability: FurnitureCapability;
    material: Array<{
        itemId: string;
        quantity: number;
    }>;
    outputs: Array<{
        itemId: string;
        quantity: number;
    }>;
    unlockConditionIds: string[];
};

```
