# 居民系统 22 · 石傀儡三形态：没头 → 没手 → 齐全

> 状态：**用户 2026-09-21 定案，开工** · 前置：零件系统（`ResidentAgent.parts`）、石傀儡咔咔（golemTalk）、建造功能开关 `golem_construction`
>
> 用户原话：石傀儡一开始没有双手。三个形态：没头没手 / 没手 / 有手有头。手通过剧情获得（剧情没想好，先 `/give`）。
> 把两只手给他 → 他回"阿咔咔咔"；给他一张图纸 → "哇咔咔" → 解锁他的建筑页面；任意图纸拿着和他说都会哇咔咔。
>
> 问答定下来的：手是**两件**物品；头 = 会说话、手 = 能干活、图纸 = 知道能盖什么；没手时是/不是改用身体演；
> 图纸**不消耗**；键位冲突走 (a)；解锁之后按 F 是「咔咔？」+ 选项「建点什么」开面板；**不做存档迁移**。

## 现状（查出来的）

- 零件系统是通用的：`static parts` + `attachedParts`，存档已存；装配交互按物品 `golemPart` 认。当初就写着"以后缺胳膊少腿加一件物品就够"。
- 造型里手臂是 `arm-left` / `arm-right` 两个节点；头挂脖子插槽、`setHeadAttached` 可摘。
- `golem_construction` 开局锁着，**没有任何剧情解锁它**——这份填的就是这个口。
- 选中图纸就自动进建筑选址（`syncHeldPreview`），`interact()` 里选址排在目标之前：拿着图纸按 F 到不了他身上。
- `golem_head` 有 placement 又没进 `chestExcludedItemIds`：开箱能抽出第二颗头（顺手修）。

## 定法

### 零件与阶段

- `Golem.parts = ["head", "arm_left", "arm_right"]`；新增 `static wakeParts`（基类 null = 全部零件都要）：石傀儡 `["head"]`。
  `dormant` 只看唤醒零件；新增 `assembled`（全齐）。
- 阶段**从零件推**，不另存：`golemStage()` → `headless` / `armless` / `complete`。
- 开局 `missingParts` 三件都缺。头照旧摆在院子西侧；手先 `/give golem_arm_left` / `golem_arm_right`，剧情以后接。
- 没手不接活：`build` 技能 `decide` 在 `!assembled` 时不出 Intent。会说话、会游荡。
- 老档不迁移（用户定）：老档里他只有头，读进来就是"没手"形态，`/give` 补上即可。

### 物品

- `golem_arm_left` / `golem_arm_right`：和头同一个路数——家具类、可摆可捡、`golemPart`、不可交易、不进开箱池。
  造型借傀儡身上那条手臂（`buildGolemArm(side)` 单独导出，装上去的和手里的一模一样）。

### 造型

- 肩上留插槽口（像脖子那样），手缺着时看得出"这儿该有条胳膊"。
- `setHeadAttached` 换成 `setPartAttached(part, on)`；ResidentView 按 `parts` 逐个喂。
- 缺手：走路不摆那条臂、干活不抡；**是/不是**改用身体：不是 = 上身往一侧歪一下再回正；是的 = 上身往前点两下。有手照旧举手。

### 剧情与对话

| 时机 | 触发 | 效果 |
|---|---|---|
| 装上任一零件 | State 发 `resident_changed{reason:"part_attached", part}` → story.ts 翻成信号 `resident_part_attached`（subject = 零件） | 聊天栏一句（装上了左手…） |
| 三件装齐 | 同上再发 `resident_assembled`（subject = definitionId） | 开对话 `golem_arms`：**阿咔咔咔** |
| 拿着图纸按 F（建造未解锁、且齐全） | RoomScene 的 (a) 例外：目标是石傀儡且建造未解锁时，F 不"选定"，交给他 | 开对话 `golem_blueprint`：**哇咔咔**；`dialogue_ended` → `unlock_feature golem_construction`。图纸不消耗 |
| 建造已解锁按 F | build 技能 `interact` 答对话 `golem_ready` | 「咔咔？」+ 选项「建点什么」→ `dialogue_event golem_open_shop` → 新效果 `open_build_shop`（面板收掉再开）；「没事」结束 |
| 没头 / 没手时按 F | 现有 | 没头：装头；没手：首次咔咔 / 之后"...." |

- 拿着图纸但他还没手：不解锁，照常按没手那条走。
- 解锁之后再拿图纸按 F：照旧是选址"选定"（例外只在解锁前生效）。
