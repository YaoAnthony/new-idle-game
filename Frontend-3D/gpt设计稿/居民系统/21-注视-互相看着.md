# 21 · 注视：说话的双方互相看着对方

> 状态：**已批（2026-09-15），一次做完** · 前置：03 对话、06 居民之间、01c 活物同步
>
> 一句话：对话一开，NPC 转过来看你、你转过去看他；坐着的不转身只转头；头跟着对方走；房客看到的也是这样。

## 用户定的（2026-09-15）

1. 玩家也转身面向 NPC（原来只有 NPC 转，玩家背对着他说话）。
2. 转身是**转过去**，不是啪地一帧到位——`stand / sit / knock` 的 `facing` 也一并改成转的。
3. **坐着不转身**，只转头（椅子上原地转圈很诡异）。
4. 头的偏转联机也要同步。

## 业界怎么做

两层：身体转向（有转速，站着才转）+ 头部注视（look-at，限角 ±45–60°，权重淡入淡出）。
Unity `SetLookAtWeight`（body / head / eyes / clamp）、Unreal `SetFocus` + LookAt 节点、Godot `LookAtModifier3D` 都是这个结构。
通用的抽象不是"对话时转身"，而是**注意力目标**：谁在跟我说话、谁走近了，都是来源，对话只是其中一个。

## 现状（改之前）

| 事 | 原来 |
|---|---|
| NPC → 你 | 对话一开 `stand(facing: 你那一拍的坐标)`，`face()` 一帧到位，是快照 |
| 你 → NPC | 没有 |
| NPC ↔ NPC（06） | 各 `stand(facing: 对方)`，同样一帧到位 |
| 头 | 没有。9 种造型里 8 种有 `head` 节点（小团子没有），玩家有 `slot-head` |
| 联机 | 身体朝向在关键帧里，但木偶只在**动词变了**时重放 `stand(facing)`——站着转过来这种不换动词的转身房客看不到 |

## 契约

**Core**

- `types/residents.ts`：`AttentionTarget = player | resident(residentId) | point(x,z)`；`AttentionSource = dialogue | pair | greet`；关键帧加 `headYaw?`。
- `types/runtime.ts`：`ParticipantTransform.headYaw?`。`NET_PROTOCOL_VERSION` 13 → 14。
- `Data/residents/attention.ts`：`attentionTuning`（转速 10、头限角 0.9 rad、头速 8、settle 0.01、来源优先级 dialogue > pair > greet）。
- `logic/attention.ts`：`wrapAngle` / `approachAngle`（走最短的一边、一阶趋近）/ `headYawToward`（相对身体、夹限角）。纯函数不带数。

**Frontend 状态层**

- `ResidentAgent`：`attend(source, target)` / `unattend(source)` / `attentionTarget()`；`headYaw`；`face()` 改写 `desiredHeading`，`tickAttention()` 每帧转身 + 转头。
  身体：走路不转；站着（含站着吃喝）有目标就一直对着目标转（目标每帧重读）；没目标转向 `face()` 给的那一下，转到就清；坐、睡、干活不转身。头：睡着、藏着不转。
  木偶：没有目标；`applyKeyframe` 把房主的 `heading`（不在走路时）写进 `desiredHeading`、`headYaw` 写进目标，转的过程自己走。
- `tickResidents`：对话冻住的那位仍跑 `tickAttention`——转过来看你正是对话要的。
- `talk.ts`：开对话 `attend("dialogue", player)`，`stand(3600)` 不再带 facing；关掉 `unattend`。敲门的那位不下 stand 但照样看你。
- `social.ts`：开聊两位互相 `attend("pair", 对方)`，`endPairTalk` 清。
- `CharacterController`：`attend / unattend`、`headYaw`；站着没走就转身，坐着只转头，躺着不转头；写进 `setLocalTransform` 第六个参数。`RoomScene` 开对话时 attend 对话对象、关掉 unattend。
- 联机：关键帧变化检测加 `headYaw`；`roster` 插值 `headYaw`；`RemotePlayersView` 贴到远端头上。

**Frontend 表现层**

- 造型的 `animate(dt, resident)` 递的是 agent，从 `resident.headYaw` 读，贴到自己的头节点：小鱼人 / 小狐 / 石傀儡 / 精灵 `head`、水獭 `head.pivot`、舒舒 `headPivot`、小龙 `headPivot`。摇头、待机左右看叠在注视之上。小团子、三只小灵没有头，只转身。
- 玩家：`rig.parts.head.rotation.y = headYaw`，在 `applyPose` 之后写（姿势表没有一条动头的 y 轴）。

**Backend**：`parseTransform` 接受可选 `headYaw`（有限、|值| ≤ π），重建对象时带上。

**走近打招呼（③，用户 2026-09-15 定要做）**：招呼那一句冒出来时 `attend("greet", 玩家, greetLookSeconds=4)`，
到点自己撤。来源表上 `greet.turnsBody = false`：**只转头不转身**——路过的人冲你抬一下头是自然的，
整个人转过来盯着你走就成了别的意思（动森的村民也是抬头看，按 A 才转身）。正在和你说话的话对话的注意力压着它。

## 不做 / 以后

- 俯仰：镜头俯视看不出来，舒舒和小团子的身高差以后再补。
- 眼睛。

## 风险

- `face()` 改成转的：所有 `stand / sit / knock / work_at` 的 facing 都从"啪"变成 ~0.3 秒的转身。坐下那一下会多一个短暂转身（用户定要）。
- 一段对话的 `dialogue_changed` 每个节点都发一次 open：attend 幂等，stand 指令照旧重下。
