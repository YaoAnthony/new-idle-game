## 步骤

1. **Core**：类型、表、决策。`Core/tests/autoLife.test.ts` 加：
   - 缺水 1 格 + 有壶有水 + 白天晴 + 门开 → `water`；
   - 壶空但有水源 → `water`；壶空且没水源 → 不排；
   - 没壶 → 不排；雨天 → 不排（雨自己浇）；暴风雨 → 不排；夜里 → 不排；门锁 → 不排；
   - 冷却中 → 跳过往下看（骰子仍能掷出溜达）；
   - 饿了和缺水同时 → 吃饭先。
2. **规划**（Systems，不寻路）：`planWateringTour(from, can)` 按 §8.3 贪心。`tests/wateringTour.test.ts`：
   - 壶满 6 格水、9 格缺水、`power 0` → 6 站 pour + 1 站 fill + 3 站 pour；`waterMaxRefills 0` → 6 站后停；
   - `power 1`、9 格挤在 3×3 → 1 站 pour 覆盖 9 格；
   - 壶空开局 → 第一站 fill；没水源且壶空 → 空清单；
   - 站的顺序是最近优先（构造三块田在不同距离）。
3. **计划器**：快照三项、`settle`。`tests/autoLifePlanner.test.ts` 加：发出去的步子是 `water`；到位后 2 秒结算记冷却；到位时限 240 秒。
4. **剧本**：`autoWater`。步骤（每一步都在 `autoTourCleanups` 里登记收场）：
   1. `plan = planWateringTour(人此刻位置, bestWateringCan())`；空 → `arrived()`。
   2. `autoStepOut(…)`：走到门里一步 → 门没开才开并记住 → 出门（不撑伞：雨天不会来这一步）。
   3. `setAutoProp(can.itemId)`。
   4. 逐站：`fill` → 站位 = 井的"贴占地一圈挑格"（把 `autoWalkToStove` 里挑格那段抽成 `standSpotBeside(placed)`）→ `tourWalk` → `tourWait(waterPourSeconds)` → `performWateringStop`；`pour` → `tourWalk(stop.at)` → `tourWait(waterPourSeconds)` → `performWateringStop`（浇 `covers`、扣水、发信号）。走不到的站跳过。
   5. `autoComeHome(…)`：回门里一步 → `setAutoProp(null)` → 自己开的门自己关 → `arrived()`。
   - 中途被打断（提前结束 / 下一步来了）：`cancelAutoTour` 收壶、清计时；已经浇过的格保留（真浇了）。
5. **指令** `/autolife water`。

## 浏览器走查

1. 六格种番茄，`/farm thirst` 全部；`/give watering_can`（空的）；开一条行动（日记本）进入专注。
2. `/autolife water`：角色起身 → 开门出去 → **先去井边**（壶空）站一会儿 → 走上田，六格逐格站住 1.5 秒、土面依次变湿 → 回屋关门 → 坐回工位。**录一段 GIF 或三张截图**：井边、田上、回座。
3. 壶预先装满：不去井边，直接上田。
4. 广口壶 `power 1`：站一格浇九格，只站一次。
5. `/weather rain` 后 `/autolife water`：什么都不做（原地视同到位）——雨天不去。
6. 不用指令，`/farm thirst` 后等 20 秒节拍：自己起身（`minWorkSeconds` 90 秒粘性过了才会）。

## 自查

- **决策不摸状态**：`decideBreak` 只读快照，`thirstyCells` 是一个数——它不知道田在哪，那是剧本的事。
- **规划不寻路**：`planWateringTour` 只按直线距离贪心；能不能走到由剧本的 `tourWalk` 说了算，走不到就跳过。两层分开，Systems 的用例才不用起场景。
- **浇是真浇**：`performWateringStop` 调的是和玩家按 F 同一个 `waterCellsAround`，扣同一把壶的水，发同一条 `building_state_changed`。
- **做客不自动**：`start()` 里现成的 `isRemoteWorldActive()` 挡在最前，本期不用再加。
- **雨天规则只有一处**：`outingWeather` 那张表；`wantsToWater` 不另写天气 if。
