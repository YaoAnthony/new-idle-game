# BUG-15-04 · 调试口硬提的委托做成后把剧情线倒着推（13 里发现并修）

- 严重度：P1（剧情阶段回退 = 功能链断）
- 来源：13 浏览器验收：咕噜在 lamp_lit 阶段被 `/npc favor offer slime_walk_to_well` 陪走一趟，`favor_completed` 把阶段退回 afraid_of_dark
- 复现（修前）：`/npc slime arc` = lamp_lit → `/npc favor offer slime_walk_to_well`、`accept`、`done` → `/npc slime arc` = afraid_of_dark
- 根因：立幕的规则只看信号不看当前幕；老档里迟到的信号（cooldown 后再做一次灯委托）也会这样
- 修法：每条立幕规则加 `requiresEventStage` 前一幕；`arcs.test` 幕序那条守着
- 同类：11 的生日 / 节日规则用 flag 门槛，不受影响
