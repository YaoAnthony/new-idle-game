## 九、我们明确不做的（和为什么）

| 动森有 | 不做的理由 |
|---|---|
| 搬走 / 不告而别 | 失去邻居是惩罚，与"不制造焦虑"冲突。换成出门几天 |
| 打人、推人、用网兜扣头导致友好度下降 | 无减分是定案 |
| 捉迷藏、寻宝限时 | 实时小游戏和挂机定位拧着 |
| HHA 评分 | 数字面板。评论代替评分 |
| 服装系统 | 生物没有换装骨架。用手持道具和饰件替代 |
| 村民数量上限 10 | 我们受地块限制，上限由领地决定，不写死 |
| amiibo 邀请 | 无对应 |
