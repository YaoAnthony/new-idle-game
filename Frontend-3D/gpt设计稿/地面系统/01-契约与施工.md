## 1. 形状

### 1.1 Core 类型（`Core/src/types/ground.ts` 末尾追加，不另开文件——"脚下踩的是什么"本来就住这里）

```ts
export type GroundId = string;
/** 一格的地面。键 = 室外房间的格坐标 "x,y"（roomCell），值 = 地面 id。没有的格 = 原生草地 */
export type GroundLayer = Record<RoomId, Record<string, GroundId>>;
/** 对偶网格上一个格点周围四格的占用（西北、东北、西南、东南） */
export type CornerMask = number; // 0..15，bit0 NW, bit1 NE, bit2 SW, bit3 SE
export type CornerShape = "none" | "corner" | "edge" | "diagonal" | "notch" | "full";
```

### 1.2 注册表 `Core/src/Data/grounds/index.ts`

```ts
export type GroundDefinition = {
  groundId: GroundId;
  localizationKey: string;           // ground.<id>
  itemId: ItemId;                     // 铺一格消耗一件；= groundId
  walkCost: number;                   // ≥ 1；A* 的启发按 1 估，小于 1 会丢最优路
  visual: { top: string; rim: string; jitter: number };  // 面色、侧棱色、逐块明度抖动（键名进 PALETTE，不写字面量）
};
export const groundTuning = { bareCost: 1.6, slabHeight: 0.04, cornerSegments: 5 };
export const groundDefinitions = [ { groundId: "sandy_road", walkCost: 1, ... } ];
export function findGroundDefinition(id): GroundDefinition | undefined;
export function groundOfItem(itemId): GroundDefinition | undefined;
```

物品：`Core/src/Data/items` 加 `sandy_road`（`ItemCategory.Material`，`ground: { groundId: "sandy_road" }` 能力块，`stackLimit 99`，`value 3`）。`ItemDefinition.ground?: { groundId }` 是新的能力块（同 `seed?`）。

### 1.3 纯逻辑 `Core/src/logic/grounds.ts`

```ts
cellKeyOf(x, y) / parseCellKey(key)
groundAt(layer, roomId, cell): GroundId | undefined
setGround(layer, roomId, cell, groundId | null): GroundLayer      // 不可变更新；null = 撬掉
groundWalkCost(layer, roomId, cell, defs, tuning): number         // 没铺 = bareCost
cornerMask(layer, roomId, groundId, cornerX, cornerY): CornerMask // 格点 (cx, cy) 周围四格：NW=(cx-1,cy-1) NE=(cx,cy-1) SW=(cx-1,cy) SE=(cx,cy)
cornerShape(mask): { shape: CornerShape; rotation: 0|1|2|3 }     // 16 → 6 形状 + 旋转（顺时针 90° 的倍数）
cornerTiles(layer, roomId, groundId): Array<{ cx, cy, mask }>    // 这种地面所有非空的格点（画面按它建）
```

对偶网格的要点：**几何画在格点上，不画在格上**。一个格点的瓦片是以格点为中心的 1×1 方块，被它周围四格中"铺了"的那些决定形状：

| mask 中为 1 的角 | 形状 | 样子 |
|---|---|---|
| 0 | none | 不画 |
| 1 | corner | 那一象限的四分之一圆（外圆角） |
| 2 相邻 | edge | 半块（直边） |
| 2 对角 | diagonal | 两个四分之一圆，不相连（两条路斜着擦肩，不连） |
| 3 | notch | 满块挖掉一个象限，挖口是圆的（内凹角） |
| 4 | full | 整块 |

于是一条直路 = 两侧一排 edge；拐角外侧 corner、内侧 notch；2×2 = 中间 full、四角 corner、四边 edge；孤零零一格 = 四个 corner 拼成一个圆角方块。**同一条规则，没有一个 if 认形状。**

### 1.4 事件、op、切片

- EventBus：`ground_changed { roomId; cell }`（视图只重建那一格周围 2×2 个格点的瓦片）。
- op（协议 v16 → **v17**）：`{ kind: "ground_set"; roomId; cell: { x, y }; groundId: string | null }`。服务端：roomId 非空 ≤ 64、cell 两个整数、groundId 字符串 ≤ 64 或 null。
- 切片 `grounds`：`sync: "refresh"`，`changedBy: ["ground_changed"]`，快照就是 `GroundLayer`。
- 信号 / 统计（顺手）：`stats.grounds_laid`（成就以后再接）。

## 2. 步骤

1. **Core**：类型、注册表、物品、纯函数。`Core/tests/grounds.test.ts`：set / lift 不可变；cost 查表与兜底；`cornerMask` 四角位序；`cornerShape` 16 种全枚举出 6 形状且旋转对（单格四角是四个 corner 各转一次；一条竖路两侧全是 edge；2×2 中心 full；L 形内角 notch；对角只碰角 diagonal）；`cornerTiles` 数量（单格 4、1×2 6、2×2 9）。
2. **State + Systems + 视图**：`grounds.ts`、`groundShapes.ts`、`GroundsView`。`tests/grounds.test.ts`（前端）：铺在领地外拒、室内拒、库存不够拒、铺一格扣一件、撬回来加一件、`groundCostAt` 路 1 草 1.6、`cornerPolygon` 六种形状顶点数与面积（corner ≈ π/16、edge = 0.5、full = 1、notch = 1 − π/16 附近）。
3. **交互**：RoomScene 目标、气泡、F、锄头撬地动作。
4. **寻路**：三处 `costOf`。`tests/groundRouting.test.ts`：一条草地上 U 形绕远的路和一条直穿草地的路——铺了路之后 `findRoute` 带 `costOf` 走路；不带 `costOf`（玩家）不变。
5. **联机**：op、切片、Backend 闸门、契约文档、`save_schema.json` 重生成、`netSession.test` +2。
6. 指令、文案、图标退化；文档收工记录。

## 4. 自查

- **形状没有 if**：`cornerShape` 是查表（16 → 6 + 旋转），画面只认 shape + rotation。
- **代价 ≥ 1**：注册表审计 `auditGrounds` 查 `walkCost >= 1`、`bareCost >= 1`、物品存在、`ground` 能力块和注册表互指。
- **玩家不吃代价**：`findRoute` 缺省 `costOf` 不变，`RoomScene` 手操走路那条不传。
- **画面和数据一份真相**：视图只读 `getGroundLayer()`，`cornerTiles` 在 Core。
- **不点名地面 id**：视图按注册表建 Mesh，加第二种地面 = 注册表一行 + PALETTE 两个色 + 一件物品。
