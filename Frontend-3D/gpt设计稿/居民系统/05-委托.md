## 玩家看到什么

- 早上出门，阿茜头顶冒一个"！"气泡站在门口等你。按 F："喏，帮我把这个交给薇尔好不好？她上次借我的。"背包里多一个"阿茜的小包"。走到薇尔那儿按 F，她接过去说一句，包消失，阿茜那边下次见面道谢。
- 咕噜："咕噜怕黑……要是有一盏灯就好了。"日记本右页多一条"咕噜想要一盏灯"。你做出云朵灯（行动开箱 / 工作台）拿给他，他收下，当晚他家窗户亮起来（02 的窗灯换成暖色，07 门口摆出那盏灯）。
- 薇尔："能请你做一道汤吗？我只闻过，没喝过。"厨房做出汤递给她。
- 某天咕噜没出门，`/npc list` 显示"在家"，窗灯白天也亮着；走到门口按 F："咕噜……有点难受。"送药（商人卖的"草药"）→ 次日恢复，好感大涨。
- 薇尔："明天下午，来我家坐坐吧。"次日 14:00~17:00 走到她家门口按 F → 一段长对话 → 送你一样东西。（08 之后是进屋。）
- 七天没做，委托消失，他不再提，也不生气。

## 动森原型与取舍

| 动森 | 取法 |
|---|---|
| 送东西给 X（"replied" 链） | `deliver`：给你一个信物，送到另一位手上 |
| 找丢的东西（NH 藏在岛上） | `find`：改成"你做出来 / 买来给他"——这是行动系统和商人的又一个出口。不做藏物 |
| 抓鱼 / 虫给我（NL） | `cook`：做一道菜 |
| 生病送药 | `sick`：取 |
| 来我家 / 去你家 | `visit_me`（这里）/ 来访（07） |
| 寻宝限时、捉迷藏 | 不做 |
| 请求过期会被村民抱怨（NL） | 不抱怨，只消失 |

### 委托定义（Core/src/Data/residents/favors.ts）

```ts
export const favorDefinitions = [
  {
    id: "slime_wants_lamp",
    residentId: "slime_neighbor",
    kind: "find",
    wants: { itemId: "cloud_lamp", quantity: 1 },
    requires: [{ kind: "affection_at_least", stage: "familiar_resident" }],   // 复用 DialogueCondition
    weight: 3,
    expiresDays: 7,
    offerDialogueId: "slime_favor_lamp_offer",
    doneDialogueId: "slime_favor_lamp_done",
    reward: { items: [{ itemId: "blueprint_slime_house_l2", quantity: 1 }] },
    onDone: [{ kind: "add_memory", memoryId: "favor_slime_lamp" }],           // 额外的剧情效果
    displayKey: "favor.slime_wants_lamp",                                      // 日记本那一行
  },
  {
    id: "fox_deliver_to_spirit",
    residentId: "fox_neighbor",
    kind: "deliver",
    token: { itemId: "favor_token_fox_parcel" },        // 信物物品（Data/items 里 kind: favor_token，不可丢弃不可卖）
    to: "spirit_neighbor",
    receiveDialogueId: "spirit_receives_fox_parcel",
    // …
  },
  { id: "spirit_wants_soup", kind: "cook", wants: { itemId: "baby_cabbage_soup", quantity: 1 }, /* … */ },
  { id: "slime_sick", kind: "sick", wants: { itemId: "herbal_medicine", quantity: 1 }, weight: 1, cooldownDays: 20, /* … */ },
  { id: "spirit_invites_you", kind: "visit_me", window: { from: "14:00", to: "17:00", dayOffset: 1 }, /* … */ },
] satisfies FavorDefinition[];

export const favorTuning = {
  /** 每天早上最多提出几件（全体居民合计） */
  offersPerDay: 1,
  /** 一位居民同时最多挂几件 */
  activePerResident: 1,
  /** 提出的保底池：连续没提出的天数越多越可能提 */
  offerPool: { base: 0.35, step: 0.15, max: 1 },
} as const;
```

五种 `kind` 的差别只在**交付条件**：

| kind | 交付 | 特殊 |
|---|---|---|
| `find` / `cook` | 手持 `wants` 物品对他按 F（走现有送礼交互，`gifting` 识别到有活跃委托要这个物品 → 走委托而不是口味判定） | `cook` 只是文案和奖励不同，规则同 `find`，**不另写代码** |
| `deliver` | 接受时给信物；手持信物对 `to` 按 F | 信物 `ItemDefinition.kind: "favor_token"`：不可丢、不可卖、不可寄售、不占任务奖励格；过期自动从背包收回 |
| `sick` | 手持药按 F | 提出当天起他**不出门**（routine 被 `sick` 状态压住：`ResidentSave.sickUntilDayId`），窗灯全天亮；过期自愈 |
| `visit_me` | 在 `window` 内到他家门口按 F | 没有物品；`dayOffset: 1` = 明天。窗口过了算过期 |

### 运行时（Systems/residents/favors.ts）

- `WorldSave.favors: Record<favorId, { residentId, offeredDayId, expiresDayId, state: "offered" | "accepted" | "done" | "expired" }>`（**新存档字段**，世界侧：委托是居民的事）。
- 每天 `day_started`：房主端按 `offerPool` 保底抽签决定今天提不提；提的话从满足 `requires`、不在 cooldown、该居民没有活跃委托的定义里**确定性加权抽**一条 → `offered`。
- `offered` → 居民头顶挂"！"（表现层读 `favors` 表；`favor` 技能把 `approach` 优先级抬高：他会主动走过来）。按 F 先播 `offerDialogueId`，结束 → `accepted`；对话里可以拒绝（选项 `emitEventId: favor_declined`）→ 直接 `expired`，不进 cooldown 惩罚。
- 交付判定在 `gifting.offerGift` 的最前面加一层：`activeFavorWanting(residentId, itemId)` → 走委托完成。**不改口味判定本身。**
- 完成：扣物品、`done`、发 `favor_completed` 信号（subject = favorId）→ storyRules 接 `adjust_affection(favor)` + `presentItems(reward)` + 定义里的 `onDone`。播 `doneDialogueId`。
- 过期：`day_started` 扫一遍，超过 `expiresDayId` → `expired`，发 `favor_expired`（没有规则接它也行，报纸不登）。信物回收。
- **委托的一切"后果"都走信号 → 规则**，favors.ts 只改 `favors` 表和收发物品。

## 技能与动词

- **`favor` 技能**（优先级 35，在 routine 之下 greet 之上）：有 `offered` 状态的委托且玩家在 12 m 内 → Intent `[walk_to 玩家附近 2m, stand(facing player)]`，并行 `gesture("exclaim")`。不追人：玩家走远就回作息。
- `sick`：不是技能，是 `routine` 的一个前置检查（`sickUntilDayId` 有效 → 整天 `hang_home` + 在家）。
- F 交互：子类 `interact()` 顺序——活跃委托的对话 > 03 的闲聊池。

## 联机

- 委托是房主与他邻居的事。房客看到"！"气泡（表现读同步过来的 `favors` 表——**`favors` 进刷新切片**，`WORLD_REFRESH_KEYS` 加一项），按 F 打开的是闲聊，不是委托对话；房客手持物品递过去走普通送礼（已被挡）。
- 房客做客期间房主完成委托 → 房客那边"！"消失、门口摆出灯（07 走家具切片）。
- 联机验收：房主 `/npc favor offer slime_wants_lamp` → 房客那边史莱姆头顶出现"！"；房客按 F 是闲聊；房主交付 → 房客那边"！"消失。

## 最容易写错的四处

1. **在 favors.ts 里加好感、发奖励。** 只发信号，规则接。
2. **信物能被丢 / 卖 / 寄售。** 三个出口都要查 `kind: favor_token`；测试各一条。
3. **`cook` 另写一套判定。** 它和 `find` 是同一条代码路径。
4. **过期没回收信物**，背包里永远躺着"阿茜的小包"。
