# Eval：v0.1.0 Initial Screen

Version：`../versions/v0.1.0-initial-screen.md`

Status：passed

## Purpose

验证 Godot Project 启动后显示一个稳定、非空、可 Resize、可 Native Adaptive Scaling 的 Initial Screen/Main Menu Shell，并且只实现 Version 允许的 Button、Placeholder Panel、fade-in 和 Quit Flow。

## Type

Hybrid：Headless Load + Manual Visual Check。

## Preconditions

- Godot `4.7.1.stable.steam` Executable 可用。
- Active Version 的 Implementation 已完成并可运行。
- 使用 Local Development Configuration。
- Backend、Network 和 MCP 均不是运行依赖。

## Setup

1. 从 Repository Root 启动 Validation。
2. 确认 Working Tree 中与本 Version 无关的改动已被识别但不会修改。
3. 准备 `480x270`、`1280x720`、`2920x1753` 和 `2560x1080` Window/Fullscreen Matrix。
4. 确认 `godot/assets/background/home/home.png` 存在。
5. 确认 IMAGE2 UI Frame Asset `godot/assets/ui/frames/modal_frame.png` 存在。
6. 确认 `modal_frame.png` 的 IMAGE2 prompt/source 已记录在 Release Evidence 或 Asset Metadata。
7. 准备 Mouse hover、Mouse click 和 Keyboard focus 检查。
8. 不安装或注入新的 External UI/Audio Asset，除本 Version 声明的 `modal_frame.png`。
9. 确认 Project Settings 使用 `1280x720` Design Viewport、`480x270` minimum Window、`canvas_items` 和 `expand`。

## Steps

1. Headless Load Project，确认 Import/Parse/Main Scene 无 Error。
2. 运行 Automated Layout Test：`"$GODOT_EXECUTABLE" --headless --log-file /tmp/new_idle_game_v0_1_layout.log --path godot --script res://tests/integration/test_v0_1_initial_screen_layout.gd`；运行 Flow Test：`"$GODOT_EXECUTABLE" --headless --log-file /tmp/new_idle_game_v0_1_flow.log --path godot --script res://tests/integration/test_v0_1_initial_screen_flow.gd`。
3. 在 `1280x720` 下运行 Project。
4. 确认 Initial Screen 非空，Home Background 覆盖 Viewport，艺术字风格 Game Title `一起做任务吧！` 可见。
5. 保存一张 Screenshot 作为 Release Evidence。
6. 将 Window 改为 `480x270`、`2920x1753` 和 `2560x1080`，或在当前显示器限制下使用最接近的独立 Window/Fullscreen Client Area。
7. 确认 Title 和四个 Button 随 Design Viewport 成比例缩放，没有重叠、裁切、Overflow、过小或离开可见区域。
8. Resize Window，确认 Layout 继续由 Godot Stretch、Anchor 和 Container 保持；不要通过真实像素 breakpoint 或 resize listener 改 UI token。
9. 用 Inspector 或 MCP 检查四个 Button group 在同一个 `VBoxContainer` 父节点下，顺序为 `新建游戏`、`继续游戏`、`设置`、`退出游戏`。
10. 检查 Menu Button Group 和外层 Layout 使用 Container/Anchor 与 Fill/Expand size flags，而不是固定 x/y position。
11. 检查 `VBoxContainer.theme_override_constants/separation` 来自 `GameStyle.BUTTON_SEPARATION`。
12. 检查 Theme color、title、button、spacing 和 modal token 集中定义在 `godot/ui/style/style.gd`。
13. 检查 Title 使用 `GameStyle.TITLE_FONT_SIZE`、`GameStyle.TITLE_OUTLINE_SIZE` 和 `GameStyle.TITLE_SHADOW_OFFSET`，呈现“手写木牌/和纸标题”方向。
14. 检查 Button 使用 `GameStyle.BUTTON_MIN_SIZE`、`GameStyle.BUTTON_CORNER_RADIUS`、`GameStyle.BUTTON_BORDER_WIDTH` 和 content margin token，呈现“柔和纸质菜单牌”方向。
15. 检查 Placeholder Panel 使用 `godot/assets/ui/frames/modal_frame.png`，并通过 `StyleBoxTexture` 或 `NinePatchRect` 进行 9-slice 缩放。
16. 检查 `modal_frame.png` 边框在 Settings/Continue/New Game Placeholder Panel 的不同内容尺寸下不变形，四角保持清晰。
17. 检查没有引入外部字体、Logo Texture、UI Kit、未知授权 UI Frame 或来自其他游戏的 Button/Title/Panel Asset。
18. 对每个 Button 执行 hover，确认 hover 状态可见，且 Button 尺寸、`VBoxContainer` 间距和整体位置不跳动。
19. 对每个 Button 执行 pressed/click，确认 pressed 状态可见，且 release 后恢复到 normal 或 hover。
20. 用 Keyboard focus 或 Inspector 检查 focus-visible 状态存在，不能只依赖极小颜色变化。
21. 确认 Title/Menu 至少有一次可观察的 `fade_in` 入场。
22. 点击 `设置`，确认打开空 Settings Panel；点击返回后回到 Main Menu。
23. 点击 `继续游戏`，确认打开空 Continue Panel；点击返回后回到 Main Menu，Debug Output 中没有 Save 读取或写入。
24. 点击 `新建游戏`，确认打开空 New Game Placeholder Panel；点击返回后回到 Main Menu，未进入 Gameplay Scene。
25. 点击 `退出游戏`，确认触发正常 quit request。
26. 重新运行 Project，通过 OS Window Close 退出。
27. 在 Godot Editor Embedded Game 中预览时，将 Preview Mode 设为 `Stretch to Fit`，确认 Editor zoom 不被误认为产品运行结果。
28. 检查 Debug Output，确认没有 Error。

## Assertions

- Project Main Scene 存在并可 Load。
- Automated Layout Test 通过。
- Initial Screen 是唯一 Player-visible Content。
- Home Background、Title 和四个 Button 在 Required Window/Fullscreen Matrix 中正确显示。
- Project Settings 使用 `1280x720` Design Viewport、`480x270` minimum Window、`canvas_items` 和 `expand`。
- Initial Screen Script 不包含真实像素 breakpoint、resize listener 或 resize-driven Theme rebuild。
- `2920x1753` 近似 Fullscreen 下 Title 和 Button 随 Design Viewport 成比例放大。
- 四个 Button 由同一个 `VBoxContainer` 管理。
- `VBoxContainer.theme_override_constants/separation` 来自 `GameStyle.BUTTON_SEPARATION`。
- Menu Button Group 使用自适应 Container/Anchor 和 Fill/Expand size flags。
- Theme 使用日系柔和绿色主色和暖橙强调色。
- Theme color 和 spacing 由 `GameStyle` token 提供，没有散落到 scene、Theme Resource 或 gameplay script。
- Title 使用 `GameStyle` title token，形成原创的手写木牌/和纸标题方向。
- Button 使用 `GameStyle` button token，形成原创的柔和纸质菜单牌方向。
- Placeholder Panel 使用 IMAGE2 生成的 `modal_frame.png`，且通过 9-slice 缩放。
- UI Frame 的 IMAGE2 prompt/source 已记录，版权来源清晰。
- Button normal、hover、pressed 和 focus-visible 状态可区分。
- Button 状态变化不会改变布局尺寸、间距或位置。
- 没有复制商业游戏 Logo、UI Kit、字体造型、Panel Frame 或外部素材。
- `fade_in` 可观察且不会遮挡最终可操作状态。
- Settings、Continue 和 New Game Placeholder Panel 均可打开并返回。
- Quit Button 触发正常 quit request。
- 没有新增 External Asset、Audio 或 Shader Dependency。
- 没有 Gameplay Node、Save Logic 或 External-service Node。
- Window Close 后 Process 正常结束。
- `Frontend/`、`Backend/` 和 `contracts/` 未修改。
