# new-idle-game

游戏关键词：联机、挂机、宠物养成、聊天、做任务、听音乐、正常白噪音。

身处奇幻魔法世界，但是做任务可以获得一些现实的物品

## 第一天流程

每个玩家会以“租到房子”的名义来到一间房子里。玩家会被随机分配到初期可选的 3 个地区之一，并随机进入某一种屋子开始生活。

比如，如果是森林系的屋子，你可能会发现一只龙猫正躺在角落里呼呼大睡。

刚搬进房子时，系统会指引你按 `B` 打开背包，把随身物品拿出来。如果物品类型是家具，就可以放在地上。

如果你第一次把工作台拿出来并放在地上，系统会引导你按 `F` 打开工作台，并告诉你它可以合成一些家具。未来需要升级工作台，才能制作更好的家具。

家具可以通过鼠标右键点击举起，再通过左键放在地上。人物走过去后，可以按 `F` 进行交互。

背包里一般会随机有 1 种家具素材，你需要用它合成家具，比如合成一张桌子或一把椅子。

期间会出现一些镜头移动事件，然后你会发现一些可爱的小动物。大胖猫除外，因为它一大个杵在那里，想看不见都难。

你可以和这些宠物进行互动，以获取最初的印象。

它们一般会有需求。如果你想满足需求，系统就会引导你解锁一个关键功能：行动。

右上角点开 UI 后，可以看到 4 种事情可选。一开始这些内容都是空的，但由于家里比较简陋，你可能只能选择一种任务。比如，家里只有桌子时可以选择学习；家里有垫子时可以选择运动任务；有画笔之类的物品时可以选择创作；有床时可以选择休息。

总之，任务分为 4 个类别：运动任务、工作或学习任务、创作任务、休息任务。具体能做什么，取决于你要应对的生物，以及家里拥有什么家具。

如果家里没有某个家具，就没办法做对应的事情。如果有的话，你需要自己创建一个这个系列的事情。创建完成后，会回到列表页，点击即可开始。

然后游戏里的角色就会开始做对应的事情，并耗费你设定的时间。

做完之后，角色会获得一些物品。一开始一定会获得能够推进剧情的物品，也就是和小宠物互动所需的物品。

之后你就可以把物品给小宠物。小宠物会展开对话，你也会了解到它的一些信息。

结束之后会获得一些对应的物资。一般它们会说，下次出门之后会给你带回来一些有趣的东西。

小宠物会给你属于它的一些素材。这时候玩家会饿，可以提示玩家去厨房区做饭。

系统提示用户可以将背包里的锅拿出来，放到灶台上，然后把米放进去开始煮饭(类overcook)。

做任务会获得番茄和鸡蛋。你可以先加鸡蛋，再加番茄。进度条结束后，食物就做好了。再从背包里拿一个盘子，就可以盛出番茄和炒饭。

你可以自己吃掉，恢复体力。

这时候会出现一个完整的 tutorial 图，展示“做任务 -> 获得奖励 -> 消耗”的流程。消耗这里会有分支：制作家具，或者把物品消耗给小动物，或者自己吃掉。

你获得材料后，可以继续制作一些家具。比如做出哑铃之后，就可以接锻炼任务。

这个时候，一般来说 4 个分类的任务都能获得一些素材。这些素材最终都能解锁最基础的 4 项任务所对应的家具。

因为玩家一开始就是下午，而且做 3 到 4 个任务后基本就到晚上了，所以可以睡觉。

第一天只能打地铺(被子枕头都在背包里)。

睡醒之后，小动物一般就不见了。但是主线任务会提示你听到某个地方有声音，让你去看看。

你过去查看后，消失的小动物就会出现。它会来找你，说上次的某个东西很不错，并给你带来了一些东西，希望以后还能继续和你相处。

你会获得一些有意思的小家具，可以放在地上。

这时候妈妈会给你打电话，问你生活得怎么样。她会说，如果物资不够，之后会给你带一个每日任务小机器过来，它也可以生成一些你需要的东西。

之后，游戏就会进入在房子里循环做任务的流程。

## 事件解锁功能

下面是一些事件会解锁的功能。

### 妈妈的礼物

妈妈在上次通话之后，送来了一个`每日任务机器(损坏)`，但是有点小损坏，需要修理一下

修好之后，获得完好的每日任务机器

`每日任务机器`，可以掉落这个世界的物品

### 救助大河

某一天暴雨时，你会听到门口有敲门声。如果你选择交互，开门后大河会倒在你的面前，你需要尝试救助大河。

救助一天之后，大河会苏醒。大河很感谢你救了自己，也听说了你的信息，于是提出：如果未来你想要出行，可以来找大河。大河会带你出门，但会要求你提供 `旅行券`。

从此，玩家获得前往其他地方的机会。目前只做联机功能。

### 联机功能

在救助了大河又或者高级工作台合成交通工具和防具后，就可以出门。出门后可以去朋友家串门，也可以和朋友一起做任务。

联机状态下，双方一起填满每日任务后，会获得友情印章。

联机状态下，双方都能看到对方在做什么事情，但选择任务也会依赖于对方的家具。

友情印章可以兑换以下物品：

- 双人家具
- 拜访动作
- 房间白噪音小组件

多人模式下，不触发剧情，可以和小动物对话，可以放置家具，可以使用多人家具，可以使用工具台，可以一起叠每日任务

代码细节上，多人模式也需要房主开启，开启时候要求上传自己的世界存档，然后其他人联机时会一起启动这个存档，直到退出存档


## 工作台

下面是工作台可以制作的东西。

### 普通工作台

普通工作台会直接展示可制作物品，并显示列表、配方以及能够制作的物品。

如果缺少材料数量，但至少拥有其中一种材料，就会标红并禁止制作，但仍然会显示出来。

工作台会检查玩家打开时的背包，以及家里所有的储存箱。

下面是可制作的物品：

1. 木头 x 1 -> 木板 x 1
2. 木头 x 1 -> 木棒 x 1
3. 木棒 x 4 + 木板 -> 桌子 x 1 或 椅子 x 1
4. 甘蔗 x 1 -> 纸 x 4
5. 纸 x 8 + 牛皮 x 1 -> 牛皮本子
6. 黑粉末 x 1 + 木棒 x 1 -> 铅笔
7. 木棒 x 4 -> 相框
8. 铁块 x 2 + 木根 -> 哑铃

可制作物品包括：

1. 桌子
2. 椅子
3. 本子
4. 笔
5. 哑铃
6. 相框
7. 花盆

### 魔法工作台

1. 天气瓶：可以改变附近的天气。

### 园艺台 / 化肥箱

1. 肥料、种子、植物相关物品。

工作台会读取玩家的背包，以及当前场景下所有箱子、储存柜，并展示可以制作的道具。

## 拍照功能

在未来的日子里，你会获得一个照相机。你可以在家里拍照，也可以和朋友合照。照相机还可以给小宠物带上，它们出门玩的时候会带照片给你。

照片由 LLM 根据事件生成，再根据事件发给玩家。

### 天气功能

这个世界默认会有不同天气，包括雨天、刮风天、晴天、阴天。不同天气下，小动物出门都会带回不一样的东西。

### 事件系统

随着时间推移，会有一系列事件发生。事件可能会对房子造成破坏，也可能带来新的变化。

目前会因为事件获得的新功能包括：

- 宠物派遣
- 宠物拍照
- 每日任务
- 更换墙纸
- 前往外地
- 扩容房子

### 每日任务

相对于 todo 性质的任务，我们也有每日任务，由妈妈赠送的每日小机器解锁。每日任务会送一些平时系列任务没办法生成的物品：

- 邮票 / 地址碎片：用于写信、解锁特殊来信或神秘收件人。
- 天气瓶：临时改变房间天气 / 白噪音，比如雨瓶、风瓶、晴瓶。
- 胶卷 / 相纸：拍照功能消耗品。
- 燃料罐：做饭需要用的能量。
- 旅行券：用来和 `大河` 交易，换取旅行的机会。

### 氪金系统

可以购买魔法棒，也可以更换墙纸。

## 小宠物系统

小宠物不是一成不变的。随着时间变化，它会进化，就和宝可梦一样。

但是进化所需的素材也需要它自己带回来。

在未来的日子里，会解锁和它们讨论的技能。

如果小宠物要出门，它们会来和你讨论去哪里。

### 好感度

宠物有针对每个人和其他宠物的记忆，其中包括好感度。

目前的设计如下：

陌生访客 -> 熟悉的住客 -> 生活伙伴 -> 家人

设计上不会显示好感度的具体数值，但是会通过以下表现表达好感度：

- 开始睡在玩家附近
- 愿意吃玩家做的饭
- 玩家做任务时在旁边陪着
- 主动带东西回来
- 出门前会询问玩家意见
- 朋友来访时不再躲起来

好感度只会在经历一些宠物事件以及陪伴事件后发生变化。

### 喜好

宠物会有自己的喜好，比如爱吃、能吃、不喜欢、不能吃的物品。

- 与天气相关的偏好
- 喜爱吃的，不爱吃的

### 派遣

派遣系统会有一套流程。初期宠物会自己直接出门，随机前往某个区域，并带回那个区域的产物。

但他们出门需要带好吃的

未来的日子里，小宠物会和你交谈，询问你更愿意前往哪个地方。

### 成长 / 进化

宠物可能会有进化趋势。目前暂时不考虑具体进化，只添加成长值即可。

## 写信功能

写信功能一直存在，但是需要具体地址才能接收到回信。

甚至你可以打破第四面墙，写信给自己。对方有概率收到你写的信，然后给你回复信息。本质上这是 LLM 回复。

## 房子装修

初期，房子的布局一直不变。但未来会认识一个生物，它可以帮助你装修房子。

## 食物系统

在途中我们会获得一些食材。你可以像 Overcooked 一样在厨房里做饭，做出来的食品可以给小动物吃。但是食物会标记属性，信息里会显示这个小动物吃不吃你做的这个东西。

厨房一开始只有灶台。下面是各种台，具体可以参考 Overcooked。只有特定食材才能放到特定厨具里。放进去之后，厨具就会开始运转。时间转动、放入食材后，食物就会自己熟。

火候只影响品质，不会烧毁稀有材料。

已解锁的菜谱，未来可以委托某些小动物炒菜。

## 植物系统

当你获得黏土后，可以制作花盆，花盆可以用来种植植物。

工作台可以制作化肥箱。

但是化肥箱很臭。如果你只有一个区域，就不能制造化肥箱，因为太臭了，玩家没办法住。

化肥箱可以允许你把过期食物放进去，并将其变成肥料。肥料可以养活一些更高级的植物。

肥料拥有等级。高等级肥料也需要高等级食物和配方。

## 正反馈

做任务获得资源后，可以做以下事情：

- 生存
- 培养宠物
- 家里装修

## 负反馈

- 食物会过期
- 做好的便当

## 疲劳值和饥饿值

疲劳值用于控制你做任务的次数。每次做休息任务以外的事情时，都会消耗疲劳值。消耗得越多，就会越累。

饥饿值用于处理你吃的食物。太饿时也没办法做任务。

饥饿度为 0 时，会停止做任何事情。

## 声音系统

声音采用对主角环境的判断。目前有以下音效。

### 天气

- 下雨天 -> 雨声
- 刮风天 -> 风声

### 家具

- 壁炉 -> 加入火焰声
- 鱼缸 -> 加入水泡声
- 风铃 -> 刮风天响
- 植物 -> 雨后有叶片滴水声
- 老钟 -> 夜晚有轻微滴答声
- 煮水 -> 咕噜咕噜的滚水声

### 宠物

- 睡觉 -> 轻微呼噜
- 开心 -> 小铃铛 / 脚步声
- 饿了 -> 轻轻叫一声
- 在旁边玩 -> 纸球、爪子、尾巴扫地
- 水生宠物 -> 吐泡泡

### 个人

- 学习 -> 纸笔声
- 运动 -> 轻微踏步声
- 创作 -> 画笔声
- 休息 -> 房间更安静
