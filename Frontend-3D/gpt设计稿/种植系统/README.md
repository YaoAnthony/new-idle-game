## 一句话

一块 3×2 的田是石傀儡盖的一栋楼，里面 6 个格各自有**土**（实土 / 耕地）和**苗**（空 / 长着 / 熟了）；
苗只在土湿的时候长，缺水不是状态、是推论；四格同种同时熟有机会并成一颗 2×2 的巨大果实；
专注期间角色自己去井边装水、挨格浇。所有阶段现算不存，所有数字在 `Core/src/Data/crops`。

## 和别的系统的关系

- **建筑系统**：田还是 `farm_plot` 建筑，施工、图纸、领地、挪拆全部现成；本系统只往它的 `state.farm` 里写东西。
- **两个世界**（[记忆：project-two-worlds-item-origin]）：番茄是测试用例。种什么、种子从哪来，等那边定了改 `Data/crops` 和商人货架，本系统的代码一行不改。
- **专注模式 01·乙**：自动浇水是那份文档"明确不做"清单里的第一项，现在做了；形状按它预留的口（决策表加一行 + 场景多认一种步子）。
- **存档 / 联机注册表**（[记忆：project-durable-state-registry]）：田的状态住 `buildings` 切片，不新开切片；`building_state_set` 是那份计划阶段 5 里的第一条 op，这里先落它一条。
