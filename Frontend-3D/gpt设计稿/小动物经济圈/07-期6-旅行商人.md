## 这一期为什么可以插队

它和主线（水獭 → 居民 → 小店 → 报纸 → 餐厅）没有依赖关系：
只要期 3 的交易面板在，它就能上。反过来主线也不等它。

**排在这个位置是因为节奏**：期 5 之后玩家的金币开始有稳定进项（小店天天
结算），这时候需要一个"值得攒钱"的去处。太早上的话玩家买不起，
"稀客"变成"每次来都只能看看"。

## 三件事

### 6A · 工具等级

**这是这一期唯一的真新机制。** 本作现在**没有"工具好坏"这个概念**：

```ts
// types/items.ts，现状
  tool?: {
    toolType: ToolType;
    maxDurability?: number;
  };
```

`ToolType` 有 `camera / hoe / watering_can / axe / fishing_rod` 五种，
但**没有任何一件真物品带 `tool` 块**，农田也不看工具——
`Systems/farming.ts` 的浇水就是"按 F、状态从干变湿"，一次一格，
没有范围这回事。

所以工具等级要从零建，形状：

```ts
  tool?: {
    toolType: ToolType;
    maxDurability?: number;

    /**
     * **这件工具能干到什么程度。** 参数的含义由 toolType 决定——
     * 水壶是"一次浇几格"，斧头会是"一下砍几棵"。
     *
     * 挂在物品上而不是另立一张"工具等级表"：升级换的是**另一件物品**
     * （铜壶 → 银壶），不是同一件东西涨了个数。这和建筑的等级不同——
     * 建筑是实例有等级，工具是**不同的东西**，玩家背包里可以同时有
     * 两把壶。做成等级表的话还要回答"这一把是几级"，而那个数字得存在
     * 哪儿又是一个问题。
     */
    power?: number;
  };
```

`Systems/farming.ts` 的浇水改成读手上那件工具的 `power`（缺省 1）：

```ts
if (action === "water") {
  const power = findItemDefinition(held?.itemId)?.tool?.power ?? 1;
  // 以这块地为中心，把周围 power 格范围内**同样需要浇水**的田一起浇了
  const watered = waterFarmsAround(instanceId, power);
  return { ok: true, did: "water", detail: `浇了 ${watered} 块` };
}
```

> 「一次喷 9 个区域」= 3×3 的范围，也就是 `power: 9` 表达"最多影响九格"，
> 或者 `power: 1` 表达"半径 1 格（含自己是 3×3）"。**选后者**：半径是
> 几何量、面积是它的推论，写半径以后加"十字形""一行"这类形状时不用改语义。
> 用户说的"9 个区域"落到数据上是 `power: 1`，注释里写清楚。

### 6B · 出摊调度

```ts
// Systems/trading.ts 里加一支，和水獭共用同一套判据
export function isTravelerHereToday(): boolean;
```

**固定周期**（`tradingTuning.travelerVisitEveryDays`，8 天）而不是随机——
理由和水獭一样：可预期让玩家能规划"下周他来，我先攒着"。**惊喜来自
"摊上有什么"，不来自"他来不来"**。

**限量存货**是这个角色的命：

```ts
/**
 * 这一趟摆什么。**确定性抽签 + 限量**。
 *
 * 不限量的话他就是第二家常驻店：好东西买得完，"这趟没赶上"的遗憾
 * 就没了，而那份遗憾正是稀客的全部价值（星露谷推车、动森狐利同款规矩）。
 *
 * 存货记在**摊位实例的 state 里**，所以买过的这一趟不会补——
 * 关掉游戏再回来还是那几件、还是买过的那几件没了。
 */
export function travelerStockOf(worldDayId: string): Array<{ itemId: string; count: number }>;
```

## 最容易写错的三处

### 一 · 限时限量是这个角色的命

不限量 = 第二家常驻店 = 稀客的价值归零。这不是洁癖，是星露谷推车和
动森狐利共同的规矩：**你能买到什么由运气决定，什么时候来由日历决定**。
两个都固定的话它就是一家开得比较少的杂货铺。

### 二 · 别和水獭撞车

两个都是"来来去去的商人"，如果周期也差不多、卖的东西也差不多，玩家
分不出他们。分工要清楚：

| | 水獭 | 旅行商人 |
|---|---|---|
| 周期 | 3 天（密） | 8 天（疏） |
| 主业 | **收**家具 | **卖**稀罕东西 |
| 副业 | 卖基础食材 | — |
| 气质 | 熟人 | 稀客 |
| 存货 | 食材不限量（日常补给） | **限量**（错过就等下一趟） |

### 三 · `power` 是半径不是面积

用户说的"一次喷 9 个区域"是 3×3。写成 `power: 1`（半径 1 格）
而不是 `power: 9`——半径是几何量，面积是它的推论。以后加"一行五格"
这类形状时，半径这个语义还能用，面积就不行了。**注释里把这条写清楚**，
否则下一个人看到 `power: 1` 会以为它只浇一格。

## 刻意不做的

- **工具耐久**（`maxDurability` 字段留着，本期不消耗——耐久是"用着用着
  就没了"的焦虑源，和定位拧着，要做也是很后面的事）
- **工具升级链**（买的是另一件物品，不是同一件涨级）
- **其他工具**（斧头、鱼竿——`power` 的语义已经通用，加是加内容）
- **旅行商人收东西**（他只卖；收货是水獭的活，两个角色的分工不能糊）
- **摊位讨价还价**
