## 多出来的四件事

### 1. 30 分钟 soak（照 `/soak-test` 的协议）

一个标签页开着不动 30 分钟，三位居民 + 石傀儡 + 水獭在场，时钟用 `/time` 每 5 分钟拨一段，天气每 10 分钟换一种。

| 观察 | 通过标准 |
|---|---|
| 内存 | `performance.memory` 30 分钟增长 < 20 MB；`ResidentView.views` 数量恒等于在场活物数（不泄漏视图） |
| 占座表 | 结束时 `/npc spots` 的占用数 == 正在 `sit` 的人数（不泄漏占座） |
| 关键帧 | 房主端出站字节稳定，不随时间涨（不累积） |
| 卡死 | 没有一只 30 分钟内位置和动词都不变（`/npc <谁> where` 抽查），除了在家睡觉的 |
| 控制台 | 零 error，warn 逐条解释 |

### 4. 联机全链压测

五人房（上限）。房主 + 4 房客同时在场 10 分钟，房主跑一遍作息、委托、来访、出门、寄信。

| 观察 | 通过 |
|---|---|
| 位置一致 | 任一时刻四个房客与房主的每只活物位置差 < 0.5 m（脚本每秒采样 `/npc where`） |
| 生灭一致 | 出门 / 回来 / 访客 在四端 5 秒内一致 |

## 收工记录（2026-09-06）

### 1. soak

面板隐藏时 RAF 和定时器都停摆，30 分钟挂机等于 0 帧。改成**加速 soak**：`__scene.update(0.1)` 推 3000 拍一段（5 游戏分钟），
六段共 18000 拍 = 30 游戏分钟，每段拨一次 `/time`、每两段换一种 `/weather`，三位居民 + 石傀儡 + 水獭在场，宿主老档。

| 观察 | 结果 | 标准 |
|---|---|---|
| 内存 | 708 → 724 MB（峰 742），+16 MB | < 20 MB ✅ |
| `ResidentView.views` | 5~6，和在场活物数一致（第六个是桥头访客 / 出门回来） | 恒等 ✅ |
| 占座表 | 结束时占用 0，没有人在坐 | 不泄漏 ✅ |
| 关键帧 | 房主的泵是 setInterval（500 ms）：隐藏标签页被节流到 ≥ 1 s，5 分钟后到每分钟一拍——**房主必须是前台页**，记入回归清单说明，不算 bug | — |
| 卡死 | **抓到一个**：阿茜和薇尔在桥头僵了 25 游戏分钟 → BUG-16-01（P1，已修，两条用例） | 零 ❌→✅ |
| 控制台 | 0 error / 0 warn | ✅ |
